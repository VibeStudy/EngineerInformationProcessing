# 기출문제 markdown 작성 규칙

문서 ID: PE

문제를 markdown 파일로 옮길 때 아래 형식을 반드시 따른다.

## 문제 형식

```markdown
Q. 문제 내용

① 선지1

② 선지2

③ 선지3

④ 선지4

> **정답: ②**
```

## 규칙 요약

- 선지(①②③④) 사이에는 빈 줄 하나씩 삽입
- 정답은 선지와 분리하여 `> **정답: N**` 형식으로 별도 표기
- 문제 사이는 `---` 구분선으로 구분
- 설명이 필요한 문제는 정답 아래에 추가 (`> 설명 내용`)
- 기출 문제 풀이 요청 시 정답과 함께 이유 설명 포함
