# 정보처리기사 실기 암기 문서 규칙

문서 ID: IP

`노트/정보처리기사_실기_암기.md` 파일은 문제 암기용 문서다.

## 구조 규칙

- `###` 단위로 구분하지 않음
- 목차는 `##` 단위만 작성
- 큰 단원은 `##` 사용
- 큰 단원 제목에는 포함된 문제 수를 `(x)` 형식으로 표기
  - 예: `## 007 요구사항 분석 (5)`

## 문제 규칙

- 문제는 사용자가 기존에 작성한 `Q.` 또는 `Q:` 형식을 유지
- 정답은 `A:` 형식을 유지
- 괄호에 들어갈 숫자 표기는 `①`, `②`, `③` 형식 사용
  - 예: `괄호(①, ②)에 들어갈 알맞은 용어를 쓰시오.`
  - 예: `( ① )`, `( ② )`
- 정답의 숫자 표기도 `①`, `②`, `③` 형식 사용
  - 예: `A: ① 유일성 ② 최소성`
- 보기 항목이 한글 기호일 때는 `㉠`, `㉡`, `㉢` 형식 사용
  - 예: `기호(㉠~㉧)로 쓰시오.`
  - 예: `㉠ Domain ㉡ Tuple ㉢ Attribute`
- 문제 사이에는 `---` 구분선을 사용
- 보기, 지문, 기호 설명은 코드블록으로 작성 가능
- 기존 문제 문체와 줄바꿈을 우선 유지
