## 생성 패턴

### Abstract Factory

* 관련 객체군을 구체 클래스에 의존하지 않고 생성할 때 사용

```java
interface Button {
    void paint();
}

class WindowsButton implements Button {
    public void paint() {
        System.out.println("Windows button");
    }
}

class MacButton implements Button {
    public void paint() {
        System.out.println("Mac button");
    }
}

interface GuiFactory {
    Button createButton();
}

class WindowsFactory implements GuiFactory {
    public Button createButton() {
        return new WindowsButton();
    }
}

class MacFactory implements GuiFactory {
    public Button createButton() {
        return new MacButton();
    }
}
```

### Builder

* 복잡한 객체를 단계별로 생성할 때 사용

```java
class User {
    private String name;
    private int age;

    private User(Builder builder) {
        this.name = builder.name;
        this.age = builder.age;
    }

    static class Builder {
        private String name;
        private int age;

        Builder name(String name) {
            this.name = name;
            return this;
        }

        Builder age(int age) {
            this.age = age;
            return this;
        }

        User build() {
            return new User(this);
        }
    }
}
```

### Factory Method

* 객체 생성을 서브클래스에 위임할 때 사용

```java
interface Document {
    void open();
}

class PdfDocument implements Document {
    public void open() {
        System.out.println("PDF open");
    }
}

abstract class DocumentCreator {
    abstract Document createDocument();
}

class PdfCreator extends DocumentCreator {
    Document createDocument() {
        return new PdfDocument();
    }
}
```

### Prototype

* 기존 객체를 복제하여 새 객체를 만들 때 사용

```java
class Report implements Cloneable {
    String title;

    Report(String title) {
        this.title = title;
    }

    public Report clone() throws CloneNotSupportedException {
        return (Report) super.clone();
    }
}
```

### Singleton

* 인스턴스를 하나만 만들고 전역 접근점을 제공할 때 사용

```java
class Config {
    private static final Config INSTANCE = new Config();

    private Config() {
    }

    static Config getInstance() {
        return INSTANCE;
    }
}
```

## 구조 패턴

### Adapter

* 호환되지 않는 인터페이스를 변환할 때 사용

```java
interface UsbC {
    void connectUsbC();
}

class UsbA {
    void connectUsbA() {
        System.out.println("USB-A connected");
    }
}

class UsbAdapter implements UsbC {
    private UsbA usbA;

    UsbAdapter(UsbA usbA) {
        this.usbA = usbA;
    }

    public void connectUsbC() {
        usbA.connectUsbA();
    }
}
```

### Bridge

* 추상화와 구현을 분리하여 각각 확장할 때 사용

```java
interface Color {
    String fill();
}

class Red implements Color {
    public String fill() {
        return "red";
    }
}

abstract class Shape {
    protected Color color;

    Shape(Color color) {
        this.color = color;
    }

    abstract void draw();
}

class Circle extends Shape {
    Circle(Color color) {
        super(color);
    }

    void draw() {
        System.out.println("circle " + color.fill());
    }
}
```

### Composite

* 단일 객체와 복합 객체를 같은 방식으로 처리할 때 사용

```java
import java.util.ArrayList;
import java.util.List;

interface Node {
    int size();
}

class FileNode implements Node {
    public int size() {
        return 1;
    }
}

class FolderNode implements Node {
    private List<Node> children = new ArrayList<>();

    void add(Node node) {
        children.add(node);
    }

    public int size() {
        return children.stream().mapToInt(Node::size).sum();
    }
}
```

### Decorator

* 기존 객체에 기능을 동적으로 추가할 때 사용

```java
interface Coffee {
    int cost();
}

class BasicCoffee implements Coffee {
    public int cost() {
        return 3000;
    }
}

class MilkDecorator implements Coffee {
    private Coffee coffee;

    MilkDecorator(Coffee coffee) {
        this.coffee = coffee;
    }

    public int cost() {
        return coffee.cost() + 500;
    }
}
```

### Facade

* 복잡한 서브시스템을 단순한 인터페이스로 감쌀 때 사용

```java
class Cpu {
    void start() {
        System.out.println("CPU start");
    }
}

class Memory {
    void load() {
        System.out.println("memory load");
    }
}

class ComputerFacade {
    private Cpu cpu = new Cpu();
    private Memory memory = new Memory();

    void boot() {
        cpu.start();
        memory.load();
    }
}
```

### Flyweight

* 같은 객체를 공유하여 메모리 사용을 줄일 때 사용

```java
import java.util.HashMap;
import java.util.Map;

class Icon {
    private String type;

    Icon(String type) {
        this.type = type;
    }
}

class IconFactory {
    private Map<String, Icon> cache = new HashMap<>();

    Icon getIcon(String type) {
        return cache.computeIfAbsent(type, Icon::new);
    }
}
```

### Proxy

* 실제 객체 접근을 대신 제어할 때 사용

```java
interface Image {
    void display();
}

class RealImage implements Image {
    public void display() {
        System.out.println("display image");
    }
}

class ImageProxy implements Image {
    private RealImage image;

    public void display() {
        if (image == null) {
            image = new RealImage();
        }
        image.display();
    }
}
```

## 행위 패턴

### Chain of Responsibility

* 요청을 처리할 수 있는 객체까지 전달할 때 사용

```java
abstract class Handler {
    protected Handler next;

    Handler link(Handler next) {
        this.next = next;
        return next;
    }

    abstract void handle(int level);
}

class InfoHandler extends Handler {
    void handle(int level) {
        if (level <= 1) {
            System.out.println("info handled");
        } else if (next != null) {
            next.handle(level);
        }
    }
}
```

### Command

* 요청을 객체로 캡슐화할 때 사용

```java
interface Command {
    void execute();
}

class Light {
    void on() {
        System.out.println("light on");
    }
}

class LightOnCommand implements Command {
    private Light light;

    LightOnCommand(Light light) {
        this.light = light;
    }

    public void execute() {
        light.on();
    }
}
```

### Interpreter

* 간단한 언어 규칙을 객체로 표현하고 해석할 때 사용

```java
interface Expression {
    boolean interpret(String context);
}

class WordExpression implements Expression {
    private String word;

    WordExpression(String word) {
        this.word = word;
    }

    public boolean interpret(String context) {
        return context.contains(word);
    }
}
```

### Iterator

* 컬렉션 내부 구조를 노출하지 않고 순회할 때 사용

```java
import java.util.Iterator;
import java.util.List;

class BookShelf implements Iterable<String> {
    private List<String> books;

    BookShelf(List<String> books) {
        this.books = books;
    }

    public Iterator<String> iterator() {
        return books.iterator();
    }
}
```

### Mediator

* 객체들이 직접 참조하지 않고 중재자를 통해 통신할 때 사용

```java
class ChatRoom {
    void send(String user, String message) {
        System.out.println(user + ": " + message);
    }
}

class ChatUser {
    private String name;
    private ChatRoom room;

    ChatUser(String name, ChatRoom room) {
        this.name = name;
        this.room = room;
    }

    void send(String message) {
        room.send(name, message);
    }
}
```

### Memento

* 객체 상태를 저장하고 나중에 복원할 때 사용

```java
class EditorMemento {
    String text;

    EditorMemento(String text) {
        this.text = text;
    }
}

class Editor {
    private String text;

    void write(String text) {
        this.text = text;
    }

    EditorMemento save() {
        return new EditorMemento(text);
    }

    void restore(EditorMemento memento) {
        text = memento.text;
    }
}
```

### Observer

* 객체 상태 변화가 생기면 의존 객체에 자동 통지할 때 사용

```java
import java.util.ArrayList;
import java.util.List;

interface Subscriber {
    void update(String news);
}

class NewsAgency {
    private List<Subscriber> subscribers = new ArrayList<>();

    void add(Subscriber subscriber) {
        subscribers.add(subscriber);
    }

    void publish(String news) {
        for (Subscriber subscriber : subscribers) {
            subscriber.update(news);
        }
    }
}
```

### State

* 상태에 따라 객체 행동을 바꿀 때 사용

```java
interface State {
    void handle();
}

class OpenState implements State {
    public void handle() {
        System.out.println("open");
    }
}

class Door {
    private State state;

    void setState(State state) {
        this.state = state;
    }

    void request() {
        state.handle();
    }
}
```

### Strategy

* 알고리즘을 캡슐화하고 실행 시점에 교체할 때 사용

```java
interface SortStrategy {
    void sort();
}

class QuickSort implements SortStrategy {
    public void sort() {
        System.out.println("quick sort");
    }
}

class Sorter {
    private SortStrategy strategy;

    Sorter(SortStrategy strategy) {
        this.strategy = strategy;
    }

    void sort() {
        strategy.sort();
    }
}
```

### Template Method

* 알고리즘 골격은 상위 클래스에 두고 세부 단계만 하위 클래스에서 구현할 때 사용

```java
abstract class DataProcessor {
    final void process() {
        read();
        parse();
        save();
    }

    abstract void read();

    abstract void parse();

    void save() {
        System.out.println("save");
    }
}
```

### Visitor

* 객체 구조는 유지하고 새로운 연산을 추가할 때 사용

```java
interface Element {
    void accept(Visitor visitor);
}

interface Visitor {
    void visit(Book book);
}

class Book implements Element {
    public void accept(Visitor visitor) {
        visitor.visit(this);
    }
}

class PriceVisitor implements Visitor {
    public void visit(Book book) {
        System.out.println("calculate price");
    }
}
```
