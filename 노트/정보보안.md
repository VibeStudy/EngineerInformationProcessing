## 네트워크 보안

### 세션 하이재킹(Session Hijacking)

* 인증이 완료된 정상 세션을 공격자가 가로채 탈취하는 공격

* TCP 시퀀스 번호 예측 또는 스니핑으로 세션 ID 획득

* 공격 과정
    1. 공격자가 클라이언트-서버 간 통신 스니핑
    2. 세션 ID 또는 TCP 시퀀스 번호 탈취
    3. 정상 클라이언트 연결 끊기(RST 패킷 전송)
    4. 탈취한 세션으로 서버에 접속

* 대응 방법
    * HTTPS(TLS) 사용으로 세션 암호화
    * 세션 ID 재발급(로그인 후 세션 ID 변경)
    * 세션 타임아웃 설정
    * IP·User-Agent 검증 추가
