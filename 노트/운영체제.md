# 운영체제

## 미들웨어

### 개념

* 분산 컴퓨팅 환경에서 서로 다른 기종 간의 하드웨어나 프로토콜, 통신 환경 등을 연결하여 운영체제와 응용 프로그램, 또는 서버와 클라이언트 사이에서 원만한 통신이 이루어지도록 다양한 서비스를 제공

* 표준화된 인터페이스를 제공해 시스템 간의 데이터 교환의 일관성 보장 

* 위치 투명성 제공. 시스템의 위치를 몰라도 논리적인 명칭만으로 액세스 가능. 

* 사용자는 미들웨어 내부 동작을 확인하려면 별도의 응용 소프트웨어 필요 

* 1:1, 1:N, N:M 등 형태로 연결 가능
