## JAVA

### 자료형 및 크기

| 자료형 | 크기 | 범위 |
|--------|------|------|
| `byte` | 1 byte (8 bit) | -128 ~ 127 |
| `short` | 2 byte (16 bit) | -32,768 ~ 32,767 |
| `int` | 4 byte (32 bit) | -2,147,483,648 ~ 2,147,483,647 |
| `long` | 8 byte (64 bit) | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| `float` | 4 byte (32 bit) | 약 ±3.4 × 10³⁸ (유효자릿수 7자리) |
| `double` | 8 byte (64 bit) | 약 ±1.8 × 10³⁰⁸ (유효자릿수 15자리) |
| `char` | 2 byte (16 bit) | 0 ~ 65,535 (Unicode) |
| `boolean` | 1 bit (JVM 구현마다 상이) | true / false |

> **특징:** C와 달리 플랫폼 독립적 — 어느 OS든 크기 동일 (JVM 보장)

## Python

### 자료형 및 크기

| 자료형 | 설명 | 크기 |
|--------|------|------|
| `int` | 정수 (크기 제한 없음) | 가변 (최소 28 byte + 자릿수에 따라 증가) |
| `float` | 부동소수점 | 8 byte (64 bit, C의 double과 동일) |
| `complex` | 복소수 | 16 byte (실수부 + 허수부 각 8 byte) |
| `bool` | 논리형 (`int` 서브클래스) | 28 byte |
| `str` | 문자열 (Unicode) | 가변 (49 byte + 문자당 1~4 byte) |
| `bytes` | 바이트 시퀀스 | 가변 |
| `list` | 동적 배열 | 가변 (56 byte + 요소당 8 byte 포인터) |
| `tuple` | 불변 시퀀스 | 가변 (40 byte + 요소당 8 byte) |
| `dict` | 해시 맵 | 가변 (240 byte~) |
| `set` | 해시 집합 | 가변 (216 byte~) |

> **특징:** Python 객체는 모두 힙 할당 — `sys.getsizeof()`로 실제 크기 확인 가능. `int`는 arbitrary precision (오버플로 없음)

## C

### 자료형 및 크기

| 자료형 | 크기 (일반적) | 범위 |
|--------|--------------|------|
| `char` | 1 byte (8 bit) | -128 ~ 127 (signed) / 0 ~ 255 (unsigned) |
| `short` | 2 byte (16 bit) | -32,768 ~ 32,767 |
| `int` | 4 byte (32 bit) | -2,147,483,648 ~ 2,147,483,647 |
| `long` | 4 or 8 byte | OS/컴파일러마다 상이 |
| `long long` | 8 byte (64 bit) | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| `float` | 4 byte (32 bit) | 약 ±3.4 × 10³⁸ (유효자릿수 6~7자리) |
| `double` | 8 byte (64 bit) | 약 ±1.8 × 10³⁰⁸ (유효자릿수 15~16자리) |
| `long double` | 8~16 byte | 컴파일러마다 상이 |
| `_Bool` | 1 byte (C99~) | 0 또는 1 |
| `bool` | 1 byte (`<stdbool.h>` 매크로, `_Bool` 별칭) | 0 또는 1 |
| `void` | 크기 없음 | — |
| 포인터 | 4 byte (32 bit OS) / 8 byte (64 bit OS) | 메모리 주소 |

> **특징:** 크기가 플랫폼·컴파일러 의존적. 정확한 크기 보장 시 `<stdint.h>`의 `int8_t`, `int32_t` 등 사용  
> `bool`은 C 기본 키워드 아님 — `#include <stdbool.h>` 필요 (C99 이상). C89/C90은 미지원

## 연산자

### 산술 연산자

* `+`, `-`, `*`, `/`, `%`

* 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 연산

### 비교 연산자

* `==`, `!=`, `>`, `<`, `>=`, `<=`

* 값 비교

### 논리 연산자

* `&&`, `||`, `!`

* AND, OR, NOT 연산

### 비트 연산자

* `&`, `|`, `^`, `~`, `<<`, `>>`

* 비트 단위 AND, OR, XOR, NOT, 좌이동, 우이동 연산

* XOR(`^`)은 두 비트가 서로 다르면 1, 같으면 0

* 예: `5 ^ 3`

```text
  5 = 0101
  3 = 0011
  5^3 = 0110 = 6
```

### 대입 연산자

* `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=`

* 값 대입과 복합 대입

### 증감 연산자

* `++`, `--`

* 전위·후위 증감 연산

* JAVA와 C에서 사용

### 조건 연산자

* `조건 ? 참 : 거짓`

* 조건식 결과에 따라 값을 선택하는 삼항 연산

### 연산자 우선순위 (높음 → 낮음)

| 순위 | 종류 | JAVA | Python | C |
|------|------|------|--------|---|
| 1 | 단항 | `++` `--` `+` `-` `~` `!` | `~` `+` `-` `not` | `++` `--` `+` `-` `~` `!` |
| 2 | 산술 (곱) | `*` `/` `%` | `**` | `*` `/` `%` |
| 3 | 산술 (합) | `+` `-` | `*` `/` `//` `%` | `+` `-` |
| 4 | 시프트 | `<<` `>>` `>>>` | `+` `-` | `<<` `>>` |
| 5 | 비교 | `<` `>` `<=` `>=` `instanceof` | `<<` `>>` | `<` `>` `<=` `>=` |
| 6 | 동등 | `==` `!=` | `==` `!=` `<` `>` `<=` `>=` `is` `in` | `==` `!=` |
| 7 | 비트 AND | `&` | `&` | `&` |
| 8 | 비트 XOR | `^` | `^` | `^` |
| 9 | 비트 OR | `\|` | `\|` | `\|` |
| 10 | 논리 AND | `&&` | `and` | `&&` |
| 11 | 논리 OR | `\|\|` | `or` | `\|\|` |
| 12 | 조건(삼항) | `? :` | `if else` | `? :` |
| 13 | 대입 | `=` `+=` `-=` … | `=` `+=` `-=` … | `=` `+=` `-=` … |

> **암기 팁:** 단항 → 산술 → 시프트 → 비교 → 동등 → 비트(AND·XOR·OR) → 논리(AND·OR) → 삼항 → 대입

#### 카테고리 내 세부 순위

| 카테고리 | 순위 (높음→낮음) | 비고 |
|----------|-----------------|------|
| **산술** | `*` `/` `%` → `+` `-` | 곱셈계 먼저 |
| **비트** | `~`(단항) → `&` → `^` → `\|` | AND→XOR→OR |
| **논리** | `!`/`not` → `&&`/`and` → `\|\|`/`or` | NOT→AND→OR |
| **대입** | 모두 동일 순위, **오른쪽→왼쪽** 결합 | `a=b=1` → b=1 먼저 |

### 언어별 차이

| 항목 | JAVA | Python | C |
|------|------|--------|---|
| 거듭제곱 | `Math.pow()` | `**` | `pow()` (math.h) |
| 정수나눗셈 | `/` (자동) | `//` 별도 연산자 | `/` (자동) |
| 논리연산자 표기 | `&&` `\|\|` `!` | `and` `or` `not` | `&&` `\|\|` `!` |
| 동일성 비교 | `==` (기본형) / `.equals()` (객체) | `==` 값 / `is` 주소 | `==` 값만 |
| 부호없는 우이동 | `>>>` | 없음 | 없음 |
| 포인터 연산 | 없음 | 없음 | `*` `&` `->` |
| 타입/멤버 확인 | `instanceof` | `in` `not in` `is` `is not` | 없음 |
| sizeof | 없음 | 없음 | `sizeof(타입)` |
| 형변환 | `(타입)값` | `int()` `float()` 내장함수 | `(타입)값` |
