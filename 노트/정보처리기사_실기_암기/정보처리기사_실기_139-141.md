## 139 인터넷 (10)
Q: 네트워크 및 인터넷과 관련된 다음 설명에 해당하는 용어를 영문으로 쓰시오.

```
• 현재 사용하고 있는 IP 주소 체계인 IPv4의 주소 부족 문제를 해결하기 위해 개발되었다.

• 각 부분을 16진수로 표현하고, 콜론(:)으로 구분한다.

• 인증성, 기밀성, 데이터 무결성의 지원으로 보안 문제를 해결할 수 있다.

• 주소의 확장성, 융통성, 연동성이 뛰어나며 실시간 흐름 제어로 향상된 멀티미디어 기능을 지원한다.
```

A: IPv6

---

Q: 인터넷에 대한 다음 설명에서 괄호(①, ②)에 들어갈 알맞은 답을 쓰시오.

```
IPv6는 ( ① )비트의 주소를 가지며, 인증성, 기밀성, 데이터 무결성의 지원으로 보안 문제를 해결할 수 있고, 주소의 확장성, 융통성, 연동성이 뛰어나다.

IPv4는 32비트의 주소를 가지며 ( ② )비트씩 4부분 총 32비트로 구성되어 있다. IPv4는 네트워크 부분의 길이에 따라 A 클래스에서 E 클래스까지 총 5단계로 구성되어 있다.
```

A: ① 128 ② 8

---

Q: IPv4의 주소 부족 문제를 해결하기 위해 개발된 IPv6의 주소 체계 세 가지를 쓰시오.

A: 유니캐스트, 멀티캐스트, 애니캐스트

---

Q: 현재 주소가 `192.168.35.10`이고 서브넷 마스크가 `255.255.252.0`인 컴퓨터에서 브로드캐스팅으로 다른 IP로 정보를 전달하려고 한다. 이때 수신할 수 있는 알맞은 IP 주소를 <보기>에서 골라 모두 작성하시오.

```
<보기> 

㉠ 192.168.32.1
㉡ 192.168.33.50
㉢ 192.168.34.126
㉣ 192.168.35.100
㉤ 192.168.35.200
```

A: ㉠, ㉡, ㉢, ㉣, ㉤

---

Q: `200.1.1.0/24` 네트워크를 FLSM 방식을 이용하여 10개의 Subnet으로 나누고, `ip subnet-zero`를 적용했다. 이때 서브네팅된 네트워크 중 10번째 네트워크의 broadcast IP 주소를 쓰시오.

A: 200.1.1.159

---

Q: 서브네팅에 대한 다음 설명에서 괄호(①, ②)에 들어갈 알맞은 답을 쓰시오.

```
현재 IP 주소가 192.168.1.132이고, 서브넷 마스크가 255.255.255.192일 때, 네트워크 주소는 192.168.1.( ① )이고, 해당 네트워크에서 네트워크 주소와 브로드캐스트 주소를 제외한 사용 가능한 호스트의 수는 ( ② )개이다.
```

A: ① 128 ② 62

---

Q: IPv6 주소 체계에 대한 다음 설명에서 괄호(①~③)에 들어갈 알맞은 용어를 쓰시오.

```
( ① )는 단일 송신자와 단일 수신자 간의 통신에 사용되는 주소 체계이다.

( ② )는 단일 송신자와 여러 수신자 간의 통신에 사용되는 주소 체계이다.

( ③ )는 단일 송신자와 가장 가까운 단일 수신자 간의 통신에 사용되는 주소 체계이다.
```

A: ① 유니캐스트 ② 멀티캐스트 ③ 애니캐스트

---

Q: 다음 IPv6 주소 표기에서 생략된 0을 모두 복원한 전체 주소를 쓰시오.

```
2001:db8::1
```

A: 2001:0db8:0000:0000:0000:0000:0000:0001

---

Q: `192.168.10.0/24` 네트워크를 4개의 Subnet으로 나눌 때, 3번째 네트워크의 네트워크 주소와 broadcast IP 주소를 쓰시오. (단, `ip subnet-zero`를 적용한다.)

A: 네트워크 주소 192.168.10.128, broadcast IP 주소 192.168.10.191

---

Q: 서브네팅에 대한 다음 설명에서 괄호(①, ②)에 들어갈 알맞은 답을 쓰시오.

```
현재 IP 주소가 172.16.5.130이고, 서브넷 마스크가 255.255.255.128일 때, 네트워크 주소는 172.16.5.( ① )이고, 해당 네트워크의 broadcast IP 주소는 172.16.5.( ② )이다.
```

A: ① 128 ② 255

## 140 OSI 참조 모델 (8)

Q: 다음이 설명하는 OSI 참조 모델의 계층을 쓰시오.

```
• 다양한 전송매체를 통해 비트 스트림을 전송한다.

• 전송에 필요한 두 장치 간의 실제 접속과 절단 등 기계적, 전기적, 기능적, 절차적 특성에 대한 규칙을 정의한다.
```

A: 물리 계층

---

Q: OSI 7 Layer에서 링크의 설정과 유지 및 종료를 담당하며, 노드 간의 오류 제어와 흐름 제어 기능을 수행하는 계층을 쓰시오.

A: 데이터 링크 계층

---

Q: OSI 7 계층에서 단말기 사이에 오류 수정과 흐름 제어를 수행하여 신뢰성 있고 명확한 데이터를 전달하는 계층을 쓰시오.

A: 전송 계층

---

Q: OSI 7 계층 중 다음 설명에 해당하는 계층을 쓰시오.

```
• 두 응용 프로세스 간의 통신에 대한 제어 구조를 제공한다.

• 연결의 생성, 관리, 종료를 위해 토큰을 사용한다.
```


A: 세션 계층

---

Q: OSI 7 Layer에 대한 다음 설명에서 각 번호(①~③)에 해당하는 계층을 쓰시오.

```
OSI 7 Layer는 다른 시스템 간의 원활한 통신을 위해 ISO에서 제안한 통신 규약이다.

① 물리적으로 연결된 두 개의 인접한 개방 시스템들 간에 신뢰성 있고 효율적인 정보 전송을 할 수 있도록 연결 설정, 데이터 전송, 오류 제어 등의 기능을 수행한다.

② 개방 시스템들 간의 네트워크 연결을 관리하며, 경로 제어, 패킷 교환, 트래픽 제어 등의 기능을 수행한다.

③ 서로 다른 데이터 표현 형태를 갖는 시스템 간의 상호 접속을 위해 필요한 계층으로, 코드 변환, 데이터 암호화, 데이터 압축, 구문 검색 등의 기능을 수행한다.
```

A: ① 데이터 링크 계층 ② 네트워크 계층 ③ 표현 계층

---

Q: OSI 7 계층을 하위 계층부터 상위 계층 순서대로 쓰시오.

A: 물리 계층 → 데이터 링크 계층 → 네트워크 계층 → 전송 계층 → 세션 계층 → 표현 계층 → 응용 계층

---

Q: OSI 7 계층 중 다음 설명에 해당하는 계층을 쓰시오.

```
• 사용자가 OSI 환경에 접근할 수 있도록 서비스를 제공한다.

• 전자우편, 파일 전송, 원격 접속 등의 서비스를 제공한다.
```

A: 응용 계층

---

Q: OSI 7 계층 중 데이터 암호화, 데이터 압축, 코드 변환 기능을 수행하는 계층을 쓰시오.

A: 표현 계층

---

## 141 네트워크 관련 장비 (10)

Q: 다음이 설명하는 네트워크 관련 장비를 쓰시오.

```
• 디지털 회선의 중간에 위치하는 것으로, 거리가 증가할수록 감쇠하는 디지털 신호의 장거리 전송을 위해 신호를 새로 재생시키거나 출력 전압을 높여 전송하는 장치이다.

• OSI 참조 모델의 물리 계층에서 동작하는 장비이다.
```

A: 리피터

---

Q: 프로토콜이 다른 네트워크를 연결시켜주는 장치로, 응용 계층을 연결하여 데이터 형식의 변환 및 프로토콜의 변환 등을 수행한다. 주로 LAN에서 다른 네트워크에 데이터를 보내거나 다른 네트워크로부터 데이터를 받아들이는 출입구 역할을 하는 네트워크 관련 장비를 쓰시오.

A: 게이트웨이

---

Q: 한 사무실이나 가까운 거리의 컴퓨터들을 연결하는 장치로 각 회선을 통합적으로 관리하며, 신호 증폭 기능을 하는 리피터의 역할도 포함하는 네트워크 장비를 쓰시오.

A: 허브

---

Q: 다음이 설명하는 네트워크 관련 장비를 쓰시오.

```
• 리피터와 동일한 기능을 수행하지만, 단순 신호 증폭뿐만 아니라 네트워크 분할을 통해 트래픽을 감소시키며, 물리적으로 다른 네트워크를 연결할 때 사용한다. 

• 데이터 링크 계층 중 MAC 계층에서 사용된다.

• 네트워크를 분산적으로 구성할 수 있어 보안성을 높일 수 있다.
```

A: 브리지

---

Q: 두 개의 서로 다른 형태의 네트워크를 상호 접속하는 3계층 장비는 무엇인지 쓰시오.

A: 라우터

---

Q: 브리지는 LAN과 LAN을 연결하거나 LAN 안에서의 컴퓨터 그룹을 연결하는 기능을 수행한다. 브리지를 이용한 서브넷 구성 시 브리지가 15개일 경우 전송 가능한 회선 수는 몇 개인지 계산식과 함께 쓰시오.

A: 15(15-1)/2 = 105개

---

Q: 다음이 설명하는 네트워크 관련 장비를 쓰시오.

```
• 브리지 기능에 더해 각 포트에 전용 대역폭을 제공한다.

• MAC 주소 테이블을 이용하여 목적지 포트로만 프레임을 전달한다.

• 데이터 링크 계층에서 동작하며, 충돌 도메인을 포트별로 분리할 수 있다.
```

A: 스위치

---

Q: 네트워크 장비와 OSI 계층에 대한 다음 설명에서 괄호(①~③)에 들어갈 알맞은 장비를 쓰시오.

```
( ① )는 물리 계층에서 동작하며, 감쇠된 신호를 증폭하거나 재생한다.

( ② )는 데이터 링크 계층에서 동작하며, MAC 주소를 기반으로 프레임을 전달한다.

( ③ )는 네트워크 계층에서 동작하며, IP 주소를 기반으로 최적 경로를 선택한다.
```

A: ① 리피터 ② 브리지 ③ 라우터

---

Q: 다음 설명에서 괄호(①, ②)에 들어갈 알맞은 네트워크 관련 장비를 쓰시오.

```
( ① )는 수신한 신호를 연결된 모든 포트로 전송하는 집선 장치이다.

( ② )는 MAC 주소 테이블을 이용하여 목적지 포트로만 프레임을 전송하며, 각 포트에 전용 대역폭을 제공한다.
```

A: ① 허브 ② 스위치

---

Q: 다음이 설명하는 네트워크 관련 장비를 쓰시오.

```
• 서로 다른 프로토콜이나 네트워크를 변환하여 연결한다.

• OSI 전 계층에 관여할 수 있다.

• 사내망과 인터넷을 연결하거나 VoIP 통신을 변환하는 데 사용될 수 있다.
```

A: 게이트웨이

---
