


## 미분류 (3)

Q: 다음 설명에서 괄호에 공통으로 들어갈 알맞은 답을 쓰시오

```
파일의 구조는 파일을 구성하는 레코드들이 보조기억장치에 편성되는 방식을 의미하는 것으로, 크게 순차, (  ), 해싱으로 구분한다. (   ) 파일 구조는 <값, 주소> 쌍으로 구성되는 데이터 구조를 활용하여 데이터에 접근하는 방식으로, 자기 디스크에서 주로 활용된다.

```
A: 색인

---

Q: 다음 설명에 해당하는 파일 구조를 쓰시오.

```
레코드를 입력된 순서나 특정 키 값의 순서에 따라 연속적으로 저장하는 방식이다. 파일의 처음부터 원하는 레코드가 나올 때까지 순서대로 접근하므로, 레코드 삽입이나 삭제가 빈번하지 않은 경우에 적합하다.
```

A: 순차 파일

---

Q: 다음 설명에 해당하는 파일 구조를 쓰시오.

```
레코드의 키 값을 해시 함수에 적용하여 저장 주소를 계산한 후, 해당 주소에 직접 접근하는 방식이다. 키 값으로부터 저장 위치를 알 수 있어 검색 속도가 빠르지만, 서로 다른 키 값이 같은 주소를 갖는 충돌이 발생할 수 있다.
```

A: 해싱 파일
