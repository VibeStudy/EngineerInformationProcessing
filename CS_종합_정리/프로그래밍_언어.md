## JAVA (2)

### 자료형 및 크기

| 자료형 | 크기 | 범위 |
|--------|------|------|
| `byte` | 1 byte (8 bit) | -128 ~ 127 |
| `short` | 2 byte (16 bit) | -32,768 ~ 32,767 |
| `int` | 4 byte (32 bit) | -2,147,483,648 ~ 2,147,483,647 |
| `long` | 8 byte (64 bit) | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| `float` | 4 byte (32 bit) | 약 ±3.4 × 10³⁸ (유효자릿수 7자리) |
| `double` | 8 byte (64 bit) | 약 ±1.8 × 10³⁰⁸ (유효자릿수 15자리) |
| `char` | 2 byte (16 bit) | 0 ~ 65,535 (Unicode) |
| `boolean` | 1 bit (JVM 구현마다 상이) | true / false |

> **특징:** C와 달리 플랫폼 독립적 — 어느 OS든 크기 동일 (JVM 보장)

### 변수명 작성 규칙

* 사용 가능 문자

  * 영문자, 숫자, 밑줄(`_`), 달러 기호(`$`) 사용 가능

  * 대소문자를 구분

* 첫 글자

  * 영문자, 밑줄(`_`), 달러 기호(`$`)만 사용 가능

  * 숫자로 시작 불가

* 사용 불가

  * 공백, 연산자, 특수문자(`@`, `#`, `-` 등) 사용 불가

  * 예약어(`int`, `class`, `public` 등)와 리터럴(`true`, `false`, `null`) 사용 불가

* 관례

  * 변수명과 메서드명은 소문자로 시작하는 카멜 표기법(camelCase) 사용

  * 예: `studentName`, `totalScore`, `_count`, `$price`

  * 오류 예: `2ndScore`, `class`, `student-name`

## Python

### 자료형 및 크기

| 자료형 | 설명 | 크기 |
|--------|------|------|
| `int` | 정수 (크기 제한 없음) | 가변 (최소 28 byte + 자릿수에 따라 증가) |
| `float` | 부동소수점 | 8 byte (64 bit, C의 double과 동일) |
| `complex` | 복소수 | 16 byte (실수부 + 허수부 각 8 byte) |
| `bool` | 논리형 (`int` 서브클래스) | 28 byte |
| `str` | 문자열 (Unicode) | 가변 (49 byte + 문자당 1~4 byte) |
| `bytes` | 바이트 시퀀스 | 가변 |
| `list` | 동적 배열 | 가변 (56 byte + 요소당 8 byte 포인터) |
| `tuple` | 불변 시퀀스 | 가변 (40 byte + 요소당 8 byte) |
| `dict` | 해시 맵 | 가변 (240 byte~) |
| `set` | 해시 집합 | 가변 (216 byte~) |

> **특징:** Python 객체는 모두 힙 할당 — `sys.getsizeof()`로 실제 크기 확인 가능. `int`는 arbitrary precision (오버플로 없음)

## C (4)

### 자료형 및 크기

| 자료형 | 크기 (일반적) | 범위 |
|--------|--------------|------|
| `char` | 1 byte (8 bit) | -128 ~ 127 (signed) / 0 ~ 255 (unsigned) |
| `short` | 2 byte (16 bit) | -32,768 ~ 32,767 |
| `int` | 4 byte (32 bit) | -2,147,483,648 ~ 2,147,483,647 |
| `long` | 4 or 8 byte | OS/컴파일러마다 상이 |
| `long long` | 8 byte (64 bit) | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| `float` | 4 byte (32 bit) | 약 ±3.4 × 10³⁸ (유효자릿수 6~7자리) |
| `double` | 8 byte (64 bit) | 약 ±1.8 × 10³⁰⁸ (유효자릿수 15~16자리) |
| `long double` | 8~16 byte | 컴파일러마다 상이 |
| `_Bool` | 1 byte (C99~) | 0 또는 1 |
| `bool` | 1 byte (`<stdbool.h>` 매크로, `_Bool` 별칭) | 0 또는 1 |
| `void` | 크기 없음 | — |
| 포인터 | 4 byte (32 bit OS) / 8 byte (64 bit OS) | 메모리 주소 |

> **특징:** 크기가 플랫폼·컴파일러 의존적. 정확한 크기 보장 시 `<stdint.h>`의 `int8_t`, `int32_t` 등 사용  
> `bool`은 C 기본 키워드 아님 — `#include <stdbool.h>` 필요 (C99 이상). C89/C90은 미지원

### 구조체

* 구조체(Structure)
  * 서로 다른 자료형의 데이터를 하나의 이름으로 묶는 사용자 정의 자료형
  * 일반 구조체의 각 멤버는 자료형 단위의 저장 공간을 사용

### 비트 필드

* 비트 필드(Bit Field)
  * 구조체 멤버에 필요한 비트 수만 지정하여 메모리를 절약하는 기능
  * 선언 형식: `자료형 멤버명 : 비트 수;`
  * 상태 플래그, 장치 제어 정보처럼 작은 정수 값을 여러 개 저장할 때 사용

```c
struct bit_field {
    unsigned char a : 2;
    unsigned char b : 3;
    unsigned char c : 4;
};
```

* 비트 폭과 저장 가능한 값
  * n비트 부호 없는 필드는 `0`부터 `2ⁿ - 1`까지 저장
  * `a : 2` → 0~3, `b : 3` → 0~7, `c : 4` → 0~15

* 크기 계산
  * 필요한 비트 수를 합산: 2비트 + 3비트 + 4비트 = 9비트
  * `unsigned char`를 저장 단위로 하는 문제에서는 1바이트에 8비트씩 저장하므로 9비트 = 2바이트
  * 비트 필드의 실제 배치와 구조체 크기는 자료형, 정렬 규칙, 컴파일러에 따라 달라질 수 있음

* 암기
  * 일반 구조체 = 멤버마다 자료형 크기만큼 저장
  * 비트 필드 = 필요한 비트 수만 저장
  * 비트 합계가 8을 넘으면 다음 바이트 사용

### 문자열 처리 표준 라이브러리 함수

* `<string.h>`에 선언된 C 표준 라이브러리 함수

* `strlen(문자열)`: 널 문자(`\0`)를 제외한 문자열 길이 반환

* `strcpy(대상, 원본)`: 원본 문자열을 대상 배열에 복사

* `strcat(대상, 원본)`: 대상 문자열 끝에 원본 문자열 연결

* `strcmp(문자열1, 문자열2)`: 두 문자열 비교
  * 같으면 `0`, 문자열1이 작으면 음수, 크면 양수 반환

* `strchr(문자열, 문자)`: 문자열에서 문자가 처음 나타나는 위치를 가리키는 포인터 반환. 없으면 `NULL`

* `strstr(문자열, 부분문자열)`: 문자열에서 부분문자열이 처음 나타나는 위치를 가리키는 포인터 반환. 없으면 `NULL`

> `strcpy()`, `strcat()` 사용 전 대상 배열에 널 문자까지 저장할 충분한 공간이 있는지 확인

## 연산자

### 산술 연산자

* `+`, `-`, `*`, `/`, `%`

* 덧셈, 뺄셈, 곱셈, 나눗셈, 나머지 연산

### 비교 연산자

* `==`, `!=`, `>`, `<`, `>=`, `<=`

* 값 비교

### 논리 연산자

* `&&`, `||`, `!`

* AND, OR, NOT 연산

### 비트 연산자

* `&`, `|`, `^`, `~`, `<<`, `>>`

* 비트 단위 AND, OR, XOR, NOT, 좌이동, 우이동 연산

* XOR(`^`)은 두 비트가 서로 다르면 1, 같으면 0

* 예: `5 ^ 3`

```text
  5 = 0101
  3 = 0011
  5^3 = 0110 = 6
```

### 대입 연산자

* `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=`

* 값 대입과 복합 대입

### 증감 연산자

* `++`, `--`

* 전위·후위 증감 연산

* JAVA와 C에서 사용

### 조건 연산자

* `조건 ? 참 : 거짓`

* 조건식 결과에 따라 값을 선택하는 삼항 연산

### 연산자 우선순위 (높음 → 낮음)

| 순위 | 종류 | JAVA | Python | C |
|------|------|------|--------|---|
| 1 | 단항 | `++` `--` `+` `-` `~` `!` | `~` `+` `-` `not` | `++` `--` `+` `-` `~` `!` |
| 2 | 산술 (곱) | `*` `/` `%` | `**` | `*` `/` `%` |
| 3 | 산술 (합) | `+` `-` | `*` `/` `//` `%` | `+` `-` |
| 4 | 시프트 | `<<` `>>` `>>>` | `+` `-` | `<<` `>>` |
| 5 | 비교 | `<` `>` `<=` `>=` `instanceof` | `<<` `>>` | `<` `>` `<=` `>=` |
| 6 | 동등 | `==` `!=` | `==` `!=` `<` `>` `<=` `>=` `is` `in` | `==` `!=` |
| 7 | 비트 AND | `&` | `&` | `&` |
| 8 | 비트 XOR | `^` | `^` | `^` |
| 9 | 비트 OR | `\|` | `\|` | `\|` |
| 10 | 논리 AND | `&&` | `and` | `&&` |
| 11 | 논리 OR | `\|\|` | `or` | `\|\|` |
| 12 | 조건(삼항) | `? :` | `if else` | `? :` |
| 13 | 대입 | `=` `+=` `-=` … | `=` `+=` `-=` … | `=` `+=` `-=` … |

> **암기 팁:** 단항 → 산술 → 시프트 → 비교 → 동등 → 비트(AND·XOR·OR) → 논리(AND·OR) → 삼항 → 대입

#### 카테고리 내 세부 순위

| 카테고리 | 순위 (높음→낮음) | 비고 |
|----------|-----------------|------|
| **산술** | `*` `/` `%` → `+` `-` | 곱셈계 먼저 |
| **비트** | `~`(단항) → `&` → `^` → `\|` | AND→XOR→OR |
| **논리** | `!`/`not` → `&&`/`and` → `\|\|`/`or` | NOT→AND→OR |
| **대입** | 모두 동일 순위, **오른쪽→왼쪽** 결합 | `a=b=1` → b=1 먼저 |

### 언어별 차이

| 항목 | JAVA | Python | C |
|------|------|--------|---|
| 거듭제곱 | `Math.pow()` | `**` | `pow()` (math.h) |
| 정수나눗셈 | `/` (자동) | `//` 별도 연산자 | `/` (자동) |
| 논리연산자 표기 | `&&` `\|\|` `!` | `and` `or` `not` | `&&` `\|\|` `!` |
| 동일성 비교 | `==` (기본형) / `.equals()` (객체) | `==` 값 / `is` 주소 | `==` 값만 |
| 부호없는 우이동 | `>>>` | 없음 | 없음 |
| 포인터 연산 | 없음 | 없음 | `*` `&` `->` |
| 타입/멤버 확인 | `instanceof` | `in` `not in` `is` `is not` | 없음 |
| sizeof | 없음 | 없음 | `sizeof(타입)` |
| 형변환 | `(타입)값` | `int()` `float()` 내장함수 | `(타입)값` |
