### 시스템 연계 및 데이터 처리 (4)

* EAI(Enterprise Application Integration)
  * 기업 내 애플리케이션과 플랫폼 사이의 정보 전달, 연계, 통합을 가능하게 하는 솔루션
  * 구현 방식
    * Point-to-Point: 애플리케이션을 1:1로 직접 연결. 변경·재사용 어려움
    * Hub & Spoke: 중앙 허브를 통해 데이터 전송. 확장·유지보수 용이, 허브 장애 시 전체 영향
    * Message Bus(ESB): 미들웨어를 통해 애플리케이션 연계. 확장성·대용량 처리 우수
    * Bus Hybrid: Hub & Spoke와 Message Bus를 혼합. 데이터 병목 최소화

* ETP(Enterprise Transaction Processing)
  * 주문, 결제, 예약 등 기업 업무 트랜잭션을 빠르고 정확하게 처리하는 방식 또는 시스템
  * 데이터 무결성, 동시성, 장애 복구를 보장하는 것이 중요

* API(Application Programming Interface)
  * 애플리케이션이 다른 애플리케이션·운영체제·서비스의 기능이나 데이터를 사용할 수 있도록 정한 인터페이스
  * 요청 형식, 응답 형식, 인증 방식, 호출 규칙 등을 정의

* ETL(Extract, Transform, Load)
  * 여러 원천 시스템에서 데이터를 추출(Extract)하고, 목적에 맞게 변환(Transform)한 뒤, 데이터 웨어하우스 등에 적재(Load)하는 과정
  * 데이터 통합, 정제, 분석용 데이터 구축에 사용

## IT 신기술 및 용어

* Mashup

  * 여러 웹 서비스나 공개 API(Application Programming Interface)의 데이터·기능을 조합해 새 서비스나 애플리케이션을 만드는 기법

  * 예: 지도 API와 부동산 정보를 결합한 매물 검색 서비스

* Grayware

  * 악성 코드로 명확히 분류되지는 않지만, 사용자에게 원치 않는 동작이나 불편을 유발할 수 있는 소프트웨어

  * 광고 표시, 사용자 행태 추적, 설정 변경 등을 수행할 수 있음

  * 애드웨어(Adware), 스파이웨어(Spyware) 등이 포함될 수 있음

* Rich Internet Application(RIA)

  * 웹 브라우저에서 실행되면서도 데스크톱 애플리케이션처럼 풍부한 사용자 인터페이스와 상호작용을 제공하는 웹 애플리케이션

  * 비동기 통신을 사용해 화면 전체를 새로고침하지 않고 일부 데이터만 갱신 가능

  * AJAX(Asynchronous JavaScript and XML), HTML5 등이 구현 기술로 사용됨

* Semantic Web

  * 웹 데이터에 의미 정보를 담은 메타데이터를 부여해 컴퓨터가 데이터의 관계와 의미를 이해·처리하도록 하는 기술

  * RDF(Resource Description Framework), OWL(Web Ontology Language), SPARQL이 대표 기술

  * 키워드 중심 검색 → 의미·관계 기반 지능형 검색

* Vaporware

  * 개발·판매·배포 계획은 발표되었지만 실제로 고객에게 판매되거나 배포되지 않은 소프트웨어

  * 개발 지연, 취소, 마케팅 목적의 사전 발표 등으로 발생

* Service-Oriented Architecture(SOA)

  * 애플리케이션 기능을 독립적인 서비스 단위로 분리하고, 표준화된 인터페이스로 연결하는 아키텍처

  * 서비스 간 결합도가 낮아 재사용성, 유연성, 상호 운용성을 높임

  * 서비스 제공자 → 서비스 저장소 → 서비스 요청자 구조로 구성 가능

* TensorFlow

  * 구글이 개발한 오픈 소스 머신러닝·딥러닝 프레임워크

  * 텐서(Tensor) 단위 데이터 연산과 모델 학습·추론을 지원

  * 이미지 인식, 자연어 처리, 추천 시스템 등에 활용


* SAMBA

  * 리눅스·유닉스에서 SMB(Server Message Block)/CIFS(Common Internet File System) 프로토콜을 구현한 오픈 소스 소프트웨어

  * Windows와 리눅스·유닉스 간 파일·프린터 공유를 지원하는 클라이언트/서버 프로그램

  * TCP 445번 포트의 직접 SMB 통신과 TCP 139번 포트의 NetBIOS 기반 SMB 통신을 사용
