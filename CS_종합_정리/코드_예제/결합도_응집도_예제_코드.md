## 결합도

### Data Coupling

* 필요한 값만 매개변수로 전달하는 결합

```java
class PriceCalculator {
    int discount(int price, int discountAmount) {
        return price - discountAmount;
    }
}

class OrderService {
    int getFinalPrice() {
        PriceCalculator calculator = new PriceCalculator();
        return calculator.discount(10000, 1000);
    }
}
```

### Stamp Coupling

* 필요한 일부 값 때문에 자료 구조 전체를 전달하는 결합

```java
class User {
    String name;
    String email;
    String address;
}

class MailService {
    void sendWelcomeMail(User user) {
        System.out.println("send to " + user.email);
    }
}
```

### Control Coupling

* 호출하는 모듈이 제어 값을 넘겨 호출된 모듈의 흐름을 결정하는 결합

```java
class ReportPrinter {
    void print(String data, boolean printSummary) {
        if (printSummary) {
            System.out.println("summary: " + data);
        } else {
            System.out.println("detail: " + data);
        }
    }
}

class ReportService {
    void printReport() {
        ReportPrinter printer = new ReportPrinter();
        printer.print("sales", true);
    }
}
```

### External Coupling

* 여러 모듈이 외부 형식이나 프로토콜에 직접 의존하는 결합

```java
class PaymentApiFormat {
    static final String DATE_FORMAT = "yyyyMMdd";
}

class PaymentSender {
    void send(String date) {
        System.out.println("send date by " + PaymentApiFormat.DATE_FORMAT);
    }
}

class PaymentLogger {
    void log(String date) {
        System.out.println("log date by " + PaymentApiFormat.DATE_FORMAT);
    }
}
```

### Common Coupling

* 여러 모듈이 전역 데이터를 공유하는 결합

```java
class GlobalConfig {
    static int taxRate = 10;
}

class OrderService {
    int addTax(int price) {
        return price + price * GlobalConfig.taxRate / 100;
    }
}

class AdminService {
    void changeTaxRate(int taxRate) {
        GlobalConfig.taxRate = taxRate;
    }
}
```

### Content Coupling

* 다른 모듈의 내부 데이터를 직접 참조하거나 수정하는 결합

```java
class Account {
    int balance;
}

class AccountService {
    void withdraw(Account account, int amount) {
        account.balance = account.balance - amount;
    }
}
```

## 응집도

### Coincidental Cohesion

* 서로 관련 없는 기능이 한 모듈에 모인 응집도

```java
class Utility {
    void printInvoice() {
        System.out.println("invoice");
    }

    void connectDatabase() {
        System.out.println("database");
    }

    void resizeImage() {
        System.out.println("image");
    }
}
```

### Logical Cohesion

* 유사한 분류의 기능을 제어 값으로 선택해 실행하는 응집도

```java
class InputReader {
    String read(String type) {
        if (type.equals("file")) {
            return "file data";
        }
        if (type.equals("keyboard")) {
            return "keyboard data";
        }
        return "network data";
    }
}
```

### Temporal Cohesion

* 같은 시점에 실행되는 기능이 한 모듈에 모인 응집도

```java
class StartupTask {
    void initialize() {
        loadConfig();
        connectDatabase();
        startScheduler();
    }

    void loadConfig() {
        System.out.println("load config");
    }

    void connectDatabase() {
        System.out.println("connect database");
    }

    void startScheduler() {
        System.out.println("start scheduler");
    }
}
```

### Procedural Cohesion

* 정해진 순서대로 실행되는 기능이 한 모듈에 모인 응집도

```java
class OrderProcedure {
    void process() {
        readOrder();
        validateOrder();
        printReceipt();
    }

    void readOrder() {
        System.out.println("read");
    }

    void validateOrder() {
        System.out.println("validate");
    }

    void printReceipt() {
        System.out.println("print");
    }
}
```

### Communication Cohesion

* 같은 입력 자료나 출력 자료를 사용하는 기능이 한 모듈에 모인 응집도

```java
class UserReport {
    void printName(User user) {
        System.out.println(user.name);
    }

    void printEmail(User user) {
        System.out.println(user.email);
    }
}
```

### Sequential Cohesion

* 한 기능의 출력이 다음 기능의 입력으로 이어지는 응집도

```java
class TextPipeline {
    void run(String text) {
        String trimmed = trim(text);
        String upper = toUpper(trimmed);
        save(upper);
    }

    String trim(String text) {
        return text.trim();
    }

    String toUpper(String text) {
        return text.toUpperCase();
    }

    void save(String text) {
        System.out.println(text);
    }
}
```

### Functional Cohesion

* 하나의 명확한 기능만 수행하는 응집도

```java
class PasswordValidator {
    boolean isValid(String password) {
        return password.length() >= 8;
    }
}
```
