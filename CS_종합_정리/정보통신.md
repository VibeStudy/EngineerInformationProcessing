## 정보이론 (10)

> 교재 1-01: 푸리에 급수·변환 / 1-02: 나이퀴스트 정리·섀넌 정리

### 신호와 주파수

* 시간 영역과 주파수 영역

  * 시간 영역(Time Domain): 시간에 따른 신호값 변화.

    * 예: 녹음한 소리의 시간별 파형

  * 주파수 영역(Frequency Domain): 신호의 주파수별 성분 표현.

    * 예: 소리에 포함된 저음·고음 성분의 크기와 위상

  * 푸리에 분석(Fourier Analysis): 신호를 사인파·코사인파 또는 복소 지수함수로 분해.

    * 같은 신호를 시간 변화와 주파수 구성으로 표현.

* 주기와 주파수

  * 주기 $T$: 신호가 한 번 반복되는 시간. 초(s) 단위.

  * 주파수 $f$: 1초 동안 반복되는 횟수. 헤르츠(Hz) 단위.
    * 주기 신호의 기본 주파수는 $f_0 = 1/T$

  * 각주파수 $\omega$: 1초 동안 변화하는 위상각. rad/s 단위.
    * $\omega = 2\pi f$, 기본 각주파수는 $\omega_0 = 2\pi/T$

* 진폭과 위상

  * 정현파 표현: $x(t) = A\cos(2\pi ft + \phi)$
    * $A$: 진폭. 정현파의 크기.

    * $f$: 주파수. 정현파의 반복 속도.

    * $\phi$: 위상. 정현파의 주기 내 위치를 나타내는 각도.

  * 주파수 스펙트럼: 주파수별 성분의 크기와 위상.

    * 신호 복원에는 크기와 위상 정보 필요.

### 푸리에 급수의 개념과 수식

* 개념

  * 푸리에 급수(Fourier Series): 주기 신호를 기본파와 정수배 고조파의 합으로 표현.

    * 주파수 성분이 $0, f_0, 2f_0, 3f_0, \ldots$처럼 이산적으로 존재

  * 표현 조건과 수렴: 구간별로 매끄러운 주기 신호 등 일반적인 공학 신호에 적용

    * 연속점: 신호값으로 수렴. 점프 불연속점: 좌우 극한의 평균으로 수렴.

* 기본 수식

  * 삼각함수 형태

    $$x(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n\cos(n\omega_0t) + b_n\sin(n\omega_0t)\right]$$

  * 푸리에 계수: 한 주기 $[t_0, t_0+T]$의 정현파별 성분 크기 계산.

    $$a_n = \frac{2}{T}\int_{t_0}^{t_0+T}x(t)\cos(n\omega_0t)\,dt \quad (n \geq 0)$$

    $$b_n = \frac{2}{T}\int_{t_0}^{t_0+T}x(t)\sin(n\omega_0t)\,dt \quad (n \geq 1)$$

  * 직류 성분(Direct Current, DC): $a_0/2$. 한 주기 신호의 평균값.

    * 시간에 따라 변하지 않는 0 Hz 성분

### 고조파와 사각파 예시

* 고조파와 사각파

  * 고조파(Harmonic): 기본 주파수의 정수배에 해당하는 성분

    * $nf_0$는 제$n$고조파이며, $f_0$는 기본파

  * 평균이 0이고 진폭이 $\pm1$인 대칭 사각파: $0<t<T/2$에서 $+1$. $T/2<t<T$에서 $-1$. 주기적으로 반복.

    * 다음과 같이 홀수차 사인파 성분의 합으로 표현

    $$x(t) = \frac{4}{\pi}\left[\sin(\omega_0t) + \frac{1}{3}\sin(3\omega_0t) + \frac{1}{5}\sin(5\omega_0t) + \cdots\right]$$

  * 깁스 현상(Gibbs Phenomenon): 유한 개 급수 항으로 불연속 신호 근사 시 발생. 불연속점 부근의 진동과 초과 상승.

    * 항 수 증가 → 진동 구간 축소. 최대 초과 상승 비율은 0으로 수렴하지 않음.

### 푸리에 변환

* 변환과 역변환

  * 푸리에 변환(Fourier Transform, FT): 시간 신호 $x(t)$를 주파수별 복소 성분 $X(f)$로 표현

    * 비주기 신호 분석에 사용. 일반적으로 연속 주파수 스펙트럼.

    * 아래 식의 $f$: Hz 단위.

    $$X(f) = \int_{-\infty}^{\infty}x(t)e^{-j2\pi ft}\,dt$$

  * 역푸리에 변환(Inverse Fourier Transform): 주파수 성분 합성 → 시간 신호 복원.

    $$x(t) = \int_{-\infty}^{\infty}X(f)e^{j2\pi ft}\,df$$

  * 복소수 표현: $j$는 $j^2=-1$을 만족하는 허수 단위

    * 오일러 공식 $e^{j\theta}=\cos\theta+j\sin\theta$로 사인·코사인 성분을 함께 표현

    * $|X(f)|$는 크기 스펙트럼, $\arg X(f)$는 위상 스펙트럼

* 푸리에 급수와의 관계

  * 주기 신호의 분해: 푸리에 급수는 일정 간격 $f_0=1/T$의 주파수 성분을 합산

  * 비주기 신호로의 확장: 유한 구간 신호를 주기적으로 반복. 반복 주기 $T$를 늘려 해석.

    * $T\to\infty$ → 주파수 간격 $1/T\to0$. 적절한 조건에서 이산 합이 연속 적분으로 연결.

  * 주기 신호의 푸리에 변환: 주기 신호에도 적용 가능.

    * 디랙 델타로 이산 선 스펙트럼 표현 가능.

* 활용

  * 음성·음악 분석: 주파수 성분 분석 → 음높이·음색 파악.

  * 필터링: 원하는 주파수 대역 통과·감쇠 → 역변환으로 신호 복원.

    * 예: 고주파 잡음 감소, 특정 주파수의 간섭 제거

  * 영상 처리와 통신: 공간 주파수 분석 → 영상 평활화·윤곽 강조.

    * 통신 신호의 대역폭과 주파수 구성 분석에 활용

### 이산 푸리에 변환과 고속 푸리에 변환

* 이산 푸리에 변환

  * 이산 푸리에 변환(Discrete Fourier Transform, DFT): 이산 시간 표본 $N$개 → 주파수 성분 $N$개.

    $$X[k] = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}, \quad k=0,1,\ldots,N-1$$

  * 주파수 간격: 표본화 주파수 $f_s$. 주파수 빈(bin) 간격 $\Delta f=f_s/N$.

    * $k$번째 빈: $kf_s/N$. 배열 뒤쪽 빈은 음의 주파수로 해석 가능.

  * 해석 시 주의점: DFT는 입력된 $N$개 표본이 주기적으로 반복된다고 해석

    * 분석 구간에 정수 개 주기가 없으면 스펙트럼 누설 가능. 성분이 여러 빈으로 분산.

    * 윈도 함수로 누설 감소. 주파수 분리 능력 등과 절충 필요.

* 고속 푸리에 변환

  * 고속 푸리에 변환(Fast Fourier Transform, FFT): DFT를 효율적으로 계산하는 알고리즘의 총칭

    * DFT와 같은 결과. 연산량 감소.

  * 계산량

    * DFT 직접 계산: $O(N^2)$

    * 대표적인 FFT 알고리즘: $O(N\log N)$

* 핵심 비교

  * 푸리에 급수: 주기 신호 → 이산적인 주파수 성분들의 합

  * 푸리에 변환: 비주기 신호까지 다루는 주파수 표현 → 일반적으로 연속적인 주파수 성분의 적분

  * DFT: 유한한 이산 시간 표본 → 유한한 이산 주파수 성분

  * FFT: DFT를 빠르게 계산하는 알고리즘

### 나이퀴스트 정리

* 나이퀴스트 무잡음 채널 전송 용량: 이상적인 무잡음 저역통과 채널의 최대 비트 전송률. 대역폭·신호 레벨 수로 결정.

  $$R_{\max}=2B\log_2 M$$

  * $B$: 채널 대역폭. Hz 단위.

  * $M$: 서로 구별 가능한 신호 레벨 수

  * $R_{\max}$: 최대 비트 전송률. bit/s 또는 bps 단위.

### 나이퀴스트 표본화 정리

* 정의: 대역 제한 아날로그 신호의 표본 복원 조건.

* 표본화 조건: 저역통과 신호의 최고 주파수 $f_{\max}$. 일반적으로 $f_s>2f_{\max}$이면 이상적 복원 가능.

* 나이퀴스트율: 신호의 최고 주파수의 2배인 $2f_{\max}$
  * 정확히 나이퀴스트율로 표본화 시 경계 성분의 위상에 따라 복원 불가능할 수 있음.

* 나이퀴스트 주파수: 표본화 주파수의 절반인 $f_s/2$

* 에일리어싱(Aliasing): 표본화 조건 미충족 시 발생. 서로 다른 주파수 성분 구별 불가.

### 섀넌 정리

* 섀넌 채널 용량 정리: 대역 제한·가산성 백색 가우스 잡음 채널의 이론적 최대 정보 전송률.

* 채널 용량 공식

  $$C=B\log_2\left(1+\frac{S}{N}\right)$$

  * $C$: 채널 용량. bps 단위.

  * $B$: 채널 대역폭. Hz 단위.

  * $S$: 평균 수신 신호 전력

  * $N$: 해당 대역폭 내 평균 잡음 전력

  * $S/N$: 신호 대 잡음비(Signal-to-Noise Ratio, SNR). 수식에는 선형 전력비 사용.

* 신호 대 잡음비의 단위 변환

  * 선형 전력비 → dB: `SNR(dB) = 10 × log₁₀(S/N)`
  * dB → 선형 전력비: `S/N = 10^(SNR(dB)/10)`
  * 30 dB → `S/N = 10^(30/10) = 1,000`.

* 계산 예시: $B=3{,}000$ Hz, $S/N=1{,}023$이면 $C=3{,}000\log_2(1{,}024)=30{,}000$ bps

### 정보 전송률 R과 채널 용량 C의 관계

* 정보 전송률 $R$: 단위 시간에 전달하는 정보량. bps 단위. 오류 제어를 위해 추가한 중복 비트는 제외

* 채널 용량 $C$: 주어진 채널의 이론적 최대 정보 전송률. 오류 확률을 임의로 작게 하는 조건.

* $R<C$: 적절한 부호화·충분히 긴 부호 길이 → 오류 확률을 임의로 감소 가능. 매 전송의 무오류 보장은 아님.

* $R=C$: 이론적 경계값. 오류 확률을 임의로 감소 가능하다는 보장은 없음.

* $R>C$: 부호화·부호 길이 변경에도 오류 확률의 임의 감소 불가. 매 전송에서 오류가 난다는 뜻은 아님.

### 나이퀴스트 정리와 섀넌 정리 비교

* 나이퀴스트 전송 용량 공식: 무잡음 채널 가정. 대역폭·신호 레벨 수로 전송률 한계 계산.

  * 암기: $2B\log_2 M$

* 섀넌 채널 용량 공식: 잡음 채널 가정. 대역폭·신호 대 잡음비로 정보 전송률 한계 계산.

  * 암기: $B\log_2(1+S/N)$

* 문제 풀이 기준: 신호 레벨 수가 주어지면 나이퀴스트 공식 검토

  * 신호 전력·잡음 전력 또는 신호 대 잡음비가 주어지면 섀넌 공식 검토

  * 두 제약 모두 적용 시 각각 계산. 더 작은 값을 상한으로 사용.

  * 실제 달성 여부는 변조 방식·장비에 따라 다름.

## 전자기파 전파 모드 (3)

### TE 모드

* 횡전기 모드(Transverse Electric, TE): 전기장이 전파 방향에 수직인 모드.

  * 정식 명칭: Transverse Electric. Electronic 아님.

* 전기장과 자기장 성분: 전파 방향: $z$축. 전기장 종방향 성분: $E_z=0$.

  * 자기장 종방향 성분: $H_z\neq0$. 횡방향 성분도 가능.

  * 전파 방향의 전기장 성분만 0. 전기장 전체가 0인 것은 아님.

### TM·TEM 모드와 비교

* 횡자기 모드(Transverse Magnetic, TM): 자기장이 전파 방향에 수직인 모드

  * $H_z=0$, $E_z\neq0$

* 횡전자기 모드(Transverse Electromagnetic, TEM): 전기장과 자기장이 모두 전파 방향에 수직인 모드

  * $E_z=0$, $H_z=0$

  * 이상적인 동축선이나 평행 2선식 전송선에서 전파 가능

* 암기 기준

  * TE: 전기장(E)의 종방향 성분이 0

  * TM: 자기장(H)의 종방향 성분이 0

  * TEM: 전기장과 자기장의 종방향 성분이 모두 0

### 도파관에서의 TE 모드

* 도파관(Waveguide): 경계 구조로 전자기파를 특정 방향에 유도.

  * 속이 빈 단일 도체 금속 도파관: TE·TM 지원. TEM 미지원.

* 차단 주파수(Cutoff Frequency): 각 모드가 진행파로 전파되는 경계 주파수.

  * 이상적 균일 도파관: 동작 주파수 > 해당 모드의 차단 주파수일 때 전파 가능.

  * 차단 주파수 아래에서는 해당 모드의 장이 진행 방향으로 지수적으로 감쇠

* 직사각형 금속 도파관의 기본 모드: 내부 폭 $a>b$일 때 $\mathrm{TE}_{10}$. 차단 주파수가 가장 낮은 지배 모드.

  * 공기 충전 시 $f_c\approx c/(2a)$. $c$: 진공 중 빛의 속도.

> 참고: [Feynman Lectures — Waveguides](https://www.feynmanlectures.caltech.edu/II_24.html), [University of Virginia — Waveguides II](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_55_Waveguides_II.html)

## 동기식·비동기식 전송 (3)

### 동기식 전송방식

* 동기식 전송(Synchronous Transmission): 송수신 비트 타이밍 동기 유지. 블록·프레임 단위 전송.

  * 문자별 시작·정지 비트 없음. 프레임 단위 경계 구분.

* 동기 유지와 프레임 구분: 별도 클록 전달 또는 수신 신호의 클록 복원으로 동기 유지.

  * 프리앰블·동기 문자·플래그 등 사용. 방식에 따라 동기 확보·프레임 경계 구분.

  * 비트 타이밍 동기와 프레임 경계 식별은 구분해서 이해

* 특징: 문자별 시작·정지 비트 없음. 대량 연속 전송 시 오버헤드 감소에 유리.

  * 프레임 헤더·트레일러·동기 정보 등의 오버헤드는 여전히 존재

  * 동기 유지·프레임 제어 필요. 실제 속도·효율은 프로토콜·장비에 따라 다름.

### 비동기식 전송방식

* 비동기식 전송(Asynchronous Transmission): 전통적 시작·정지 방식 기준. 시작 비트로 문자별 동기 확보. 정지 비트로 문자 종료 구분.

  * 문자 사이 간격: 가변. 문자 내부 비트 간격: 설정 속도에 따라 일정.

  * 송수신 설정 일치 필요. 전송 속도·데이터 비트 수·패리티·정지 비트 길이.

* 문자 프레임 구성: 시작 비트 → 데이터 비트 → 선택적 패리티 비트 → 정지 비트

  * 일반적인 UART(Universal Asynchronous Receiver/Transmitter) 논리값: 유휴 1, 시작 0, 정지 1.

  * 실제 전압 극성은 전기적 인터페이스에 따라 다름.

* 8N1 설정: 데이터 8비트·패리티 없음(None)·정지 1비트. 시작 1비트 추가.

  * 문자당 총 10비트. 문자 사이 유휴 시간 없을 때 효율 $8/10=80\%$.

  * 9,600 bit/s 연속 전송: 최대 $9{,}600/10=960$문자/s. 순수 데이터율 $960\times8=7{,}680$ bit/s.

  * 상위 프로토콜 오버헤드 제외. 문자 사이 유휴 시간 발생 → 실제 처리율 감소.

* 특징: 필요할 때 문자 단위 전송. 간헐적 소량 데이터에 적합.

  * 문자마다 시작·정지 비트가 붙어 부가 비트의 비율이 커질 수 있음

### 동기식·비동기식 비교

* 동기 기준

  * 동기식: 프레임 전송 중 비트 타이밍 동기 유지

  * 비동기식: 문자별 시작 비트로 동기 재설정. 문자 사이 간격 가변.

* 전송 단위와 부가 정보

  * 동기식: 블록·프레임 단위 전송. 프레임별 제어 정보 사용.

  * 비동기식: 문자별 시작·정지 비트 사용. 필요 시 패리티 추가.

* 구분 시 주의점: 비동기식도 문자 내부 비트 동기 필요.

  * 동기식도 반드시 별도의 클록 선을 사용하는 것은 아님

  * 시간 동기·프레이밍 기준 분류. 직렬·병렬, 단방향·반이중·전이중과 별개.

  * 동기식 TDM의 고정 슬롯 배정과 비동기식 전송의 시작·정지 방식은 서로 다른 분류 기준

* 암기 핵심

  * 동기식: 프레임 단위 → 동기 유지 → 대량 연속 전송에 유리

  * 비동기식: 문자 단위 → 시작·정지 비트 → 문자 사이 간격 가변

## 펄스 부호 변조 (5)

### PCM 개념과 처리 순서

* 펄스 부호 변조(Pulse Code Modulation, PCM): 아날로그 신호를 일정 간격으로 측정. 유한 레벨로 근사 후 디지털 비트열로 표현.

* 송신 과정: 표본화(Sampling) → 양자화(Quantization) → 부호화(Encoding)

  * 표본화: 시간 이산화. 양자화: 진폭 이산화. 부호화: 양자화값을 비트열로 표현.

* 수신 과정: 비트열 복호화 → 양자화 레벨에 대응하는 표본값 생성 → 복원 필터로 아날로그 신호 복원

  * 양자화로 손실된 정보는 일반적으로 완전 복원 불가.

### 표본화

* 표본화 주파수와 주기

  * 표본화 주파수 $f_s$: 1초 동안 취하는 표본 수. Hz 또는 samples/s 단위.

  * 표본화 주기 $T_s$: 인접 표본 사이 시간 간격. $T_s=1/f_s$.

* 표본화 조건: 최고 주파수가 $f_{\max}$인 대역 제한 저역통과 신호는 일반적으로 $f_s>2f_{\max}$로 표본화

  * 시험: 최소 표본화 주파수로 $2f_{\max}$를 주로 사용. 실제 설계: 필터 특성을 고려해 여유 확보.

* 에일리어싱 방지: 표본화 전에 저역통과 필터를 적용하여 $f_s/2$ 이상의 주파수 성분을 충분히 억제

  * 표본화 후 겹친 주파수 성분은 일반적으로 분리 불가.

### 양자화

* 양자화 레벨과 비트 수: 연속적인 표본 진폭을 유한한 대표값 중 하나로 근사

  * 표본당 $n$비트 → 양자화 레벨 수 $L=2^n$.

  * 예: 8비트 양자화는 256개 레벨 표현

* 균일 양자화: 양자화 간격을 일정하게 설정하는 방식

  * 입력 범위 $V_{\min}\sim V_{\max}$를 동일한 $L$개 구간으로 분할. 양자화 간격 $\Delta=(V_{\max}-V_{\min})/L$.

* 양자화 오차와 잡음: 실제 표본값과 양자화된 대표값의 차이가 양자화 오차

  * 구간 중앙값으로 반올림·입력 범위 내 조건. 최대 오차 크기 $\Delta/2$.

  * 비트 수 증가 → 양자화 간격·잡음 감소. 필요 전송률 증가.

  * 입력이 허용 범위를 벗어나면 과부하 왜곡이 발생

* 비균일 양자화와 압신: 작은 진폭: 좁은 간격. 큰 진폭: 넓은 간격. 작은 신호의 상대적 양자화 오차 감소.

  * 압신(Companding): 송신 측 진폭 압축 → 수신 측 신장.

  * 대표적인 압신 특성은 A-law와 μ-law

### 부호화와 전송률

* 부호화: 각 양자화 레벨에 대응하는 이진 부호를 부여

  * 표본값을 비트열로 표현하는 단계. 오류 정정·선로 부호화와 구분.

* PCM 비트 전송률

  $$R_b=f_s\times n$$

  * $R_b$: 비트 전송률. bps 단위.

  * $f_s$: 초당 표본 수

  * $n$: 표본당 비트 수

  * 동일 조건 $K$개 채널 다중화 → 순수 PCM 전송률 $Kf_sn$.

  * 동기·제어·오류 정정 비트 추가 → 필요 전송률 증가.

* 음성 PCM 계산 예시: 표본화 주파수 8,000 Hz, 표본당 8비트이면 $R_b=8{,}000\times8=64{,}000$ bps = 64 kbps

  * 표본화 주기는 $T_s=1/8{,}000=125$ μs

  * 64 kbps는 비트 전송률. 필요 채널 대역폭은 선로 부호·변조 방식 등에 따라 다름.

### PCM 특징과 관련 방식

* 장점과 한계: 디지털 신호 재생·오류 제어 가능. 저장·처리·다중화에 적합.

  * 표본화·양자화 제약 존재. 표본화 주파수·비트 수 증가 → 품질 향상·데이터량 증가.

* 차분·적응 부호화: DPCM과 ADPCM의 원리 및 ADM과의 차이는 [예측 부호화와 적응 변조](#예측-부호화와-적응-변조-2) 참고

* 델타 변조(Delta Modulation, DM): 이전 복원값 대비 증가·감소 방향 표현. 표본당 1비트.

  * 빠른 신호 변화: 경사 과부하 왜곡. 완만한 구간: 계단 변화에 따른 입상 잡음.

* 암기 핵심

  * 처리 순서: 표본화 → 양자화 → 부호화

  * 레벨 수: $L=2^n$

  * 전송률: $R_b=f_sn$

  * 대표 음성 PCM: 8 kHz × 8비트 = 64 kbps

## 예측 부호화와 적응 변조 (2)

### DPCM

* 차분 펄스 부호 변조(Differential Pulse Code Modulation, DPCM): 현재 표본값과 예측값의 차이를 양자화·부호화.

  * 인접 표본의 상관관계 이용. 예측 오차 범위가 작으면 같은 품질의 필요 비트 수 감소 가능.

* 처리 과정: 과거 복원 표본으로 현재 값 예측 → 현재 표본과 예측값의 차이 계산 → 차분 양자화 → 부호화

  * 수신 측도 같은 예측 규칙 사용. 예측값 + 복호화한 차분 → 표본 복원.

  * 송신 측도 양자화 차분으로 복원한 표본 사용. 송수신 예측 상태 일치.

* PCM과의 비교

  * 펄스 부호 변조(Pulse Code Modulation, PCM): 표본의 진폭값을 양자화하여 표현

  * DPCM: 표본의 예측 오차를 양자화하여 표현

  * 단순 예측: 직전 표본과의 차분 사용. 일반적으로 여러 과거 표본으로 예측 가능.

### ADM

* 적응 델타 변조(Adaptive Delta Modulation, ADM): 입력 변화에 따라 델타 변조(Delta Modulation, DM)의 계단 크기 조절.

  * 기본 DM처럼 표본마다 이전 복원값에 대한 증가·감소 방향을 1비트로 표현

* 계단 크기 조절: 같은 방향 비트 연속 → 계단 크기 증가. 빠른 신호 변화 추종.

  * 증가·감소 방향의 잦은 교대 → 계단 크기 감소. 완만한 구간의 오차 감소.

  * 수신 측도 동일한 적응 규칙으로 계단 크기를 갱신하여 복원

* 개선하는 왜곡

  * 경사 과부하 왜곡: 계단 추종보다 빠른 입력 변화로 발생. 계단 크기 증가로 완화.

  * 입상 잡음: 완만한 신호 주위의 계단 진동으로 발생. 계단 크기 감소로 완화.

  * 적응으로 두 문제 완화. 모든 입력에서 완전 제거는 불가.

* ADPCM과의 구분

  * 적응 차분 펄스 부호 변조(Adaptive Differential Pulse Code Modulation, ADPCM): DPCM의 양자화 간격이나 예측 특성 등을 적응적으로 조절

  * ADM: 기본적으로 1비트 델타 변조의 계단 크기를 조절

> PCM의 표본화·양자화·부호화와 전송률 계산은 [펄스 부호 변조](#펄스-부호-변조-5) 단원 참고

## 다중화 (3)

### TDM

* 시분할 다중화(Time Division Multiplexing, TDM): 하나의 회선을 시간 슬롯으로 분할. 여러 채널이 번갈아 사용.

  * 시간 슬롯으로 채널 데이터 분리. 송수신 동기 필요.

* 동기식 TDM: 각 채널에 정해진 시간 슬롯을 주기적으로 할당

  * 데이터 없는 채널에도 슬롯 배정. 회선 이용 효율 저하 가능.

* 통계적 TDM: 전송할 데이터가 있는 채널에 시간 슬롯을 동적으로 할당

  * 채널 식별 정보·버퍼 필요. 트래픽 집중 시 대기 지연.

* 전송률 계산: 채널당 입력률 $r$ bps. $K$개 채널 고정 슬롯 수용 → 순수 전송률 $Kr$ bps.

  * 동기·제어 비트가 있으면 실제 회선 전송률에 추가 반영

  * 예: 64 kbps PCM 채널 24개를 수용하면 순수 데이터 전송률은 $24\times64=1{,}536$ kbps

### FDM

* 주파수 분할 다중화(Frequency Division Multiplexing, FDM): 전송 대역을 여러 부대역으로 분할. 채널별 동시 전송.

  * 서로 다른 반송파에 신호 배치. 채널 대역 중첩 방지.

* 보호 대역(Guard Band): 인접 채널 사이의 주파수 간격. 채널 간 간섭 감소.

  * 보호 대역·필터 특성 고려 필요. 실제 필요 대역폭은 신호 대역폭 합보다 클 수 있음.

* 대역폭 계산: 채널 대역폭 $B$, 채널 수 $K$, 보호 대역폭 $G$. 전체 대역폭 $KB+(K-1)G$.

  * 양 끝 여유 대역 제외. 인접 채널 사이에 동일 보호 대역 적용.

  * 예: 4 kHz 채널 3개, 보호 대역 1 kHz이면 $3\times4+2\times1=14$ kHz

* 활용: 방송 신호 분배, 케이블 전송 등에서 여러 주파수 채널을 하나의 매체로 전달

### TDM과 FDM 비교

* 자원 분할 기준

  * TDM: 시간 분할. 채널별 순차 전송.

  * FDM: 주파수 분할. 서로 다른 대역에서 동시 전송.

* 채널 분리에 필요한 요소

  * TDM: 시간 슬롯과 프레임 동기

  * FDM: 주파수 선택 필터와 보호 대역

* 신호 종류와의 관계: TDM은 디지털 통신, FDM은 아날로그 통신에서 대표적으로 사용

  * FDM도 디지털 변조 신호 전송 가능. 신호 종류만으로 구분 불가.

* 암기 핵심

  * TDM: 시간 슬롯 분할

  * FDM: 주파수 대역 분할

## 회선 제어와 다중 접근 (4)

### ALOHA

* 임의 접근 방식: 공유 매체에 경쟁적으로 접근. 전송 전 채널 사용 여부 미감지.

  * 프레임 중첩·충돌 시 전송 실패 가능. 확인 응답 없으면 임의 대기 후 재전송.

* 순수 ALOHA(Pure ALOHA): 전송할 프레임이 생기면 시각 제한 없이 바로 전송

  * 프레임 전송 시간이 모두 $T$일 때 충돌 취약 구간은 $2T$

* 슬롯 ALOHA(Slotted ALOHA): 프레임 전송 시간 단위로 슬롯 분할. 슬롯 시작에만 전송.

  * 단말 간 슬롯 동기 필요. 충돌 취약 구간 $T$.

  * 같은 슬롯의 동시 전송 시 충돌 가능.

* 이론적 최대 처리율: 동일 프레임 길이·포아송 전송 시도 가정. 프레임 중첩 시 실패하는 이상적 모형.

  * $G$: 프레임 전송 시간당 평균 전송 시도 수. 재전송 포함.

  * $S$: 프레임 전송 시간당 평균 성공 프레임 수

  * 순수 ALOHA: $S=Ge^{-2G}$이며 $G=1/2$에서 최대 $1/(2e)\approx0.184$, 약 18.4%

  * 슬롯 ALOHA: $S=Ge^{-G}$이며 $G=1$에서 최대 $1/e\approx0.368$, 약 36.8%

### Polling

* 폴링(Polling): 주국(Primary Station)이 종국(Secondary Station)의 송신 데이터 확인. 종국에 송신 기회 부여.

  * 제어 요청은 주국 → 종국, 실제 데이터는 종국 → 주국 방향

* 기본 동작: 주국의 POLL 전송 → 종국의 데이터 전송 → 주국의 수신 확인

  * 데이터 없으면 종국이 프로토콜에 따라 부정 응답 등 전송. 주국은 다음 종국 확인.

* 특징: 주국이 전송 기회 통제. 통제된 단말 간 경쟁 충돌 방지 가능.

  * 데이터 없는 종국 확인에도 제어 오버헤드 발생. 송신 차례까지 대기 지연.

  * 중앙 주국 의존 시 주국 장애가 전체 통신에 영향 가능.

### Selecting

* 셀렉팅(Selecting): 주국이 수신할 종국 선택. 수신 준비 상태 확인.

  * 제어 요청과 실제 데이터 모두 주국 → 종국 방향

* 기본 동작: 주국의 SEL 전송 → 종국의 수신 가능 응답 → 주국의 데이터 전송 → 종국의 수신 확인

  * 종국 수신 불가 → 부정 응답 등에 따라 전송 보류·재시도.

  * 기본 동작 기준. 선택 요청·데이터를 연속 전송하는 변형도 존재.

### ALOHA·Polling·Selecting 비교

* 접근 제어 주체

  * ALOHA: 단말이 자율적으로 전송을 시도하는 경쟁 방식

  * Polling·Selecting: 주국이 종국의 송수신을 통제하는 방식

* 주국의 목적

  * Polling: 종국이 보낼 데이터를 받아오기

  * Selecting: 선택한 종국으로 데이터를 보내기

* 암기 핵심

  * ALOHA: 일단 전송 → 실패 시 임의 대기 → 재전송

  * Polling: 주국이 묻고 종국이 송신

  * Selecting: 주국이 선택하고 주국이 송신
