## 정보이론 (7)

> 교재 1-01: 푸리에 급수·변환 / 1-02: 나이퀴스트 정리·섀넌 정리

### 신호와 주파수


* 시간 영역과 주파수 영역

  * 시간 영역(Time Domain)
    * 시간에 따라 신호의 값이 어떻게 변하는지 표현

    * 예: 녹음한 소리의 시간별 파형

  * 주파수 영역(Frequency Domain)
    * 신호에 어떤 주파수 성분이 얼마나 포함되어 있는지 표현

    * 예: 소리에 포함된 저음·고음 성분의 크기와 위상

  * 푸리에 분석(Fourier Analysis)
    * 신호를 사인파·코사인파 또는 복소 지수함수 성분으로 분해하는 방법

    * 같은 신호를 시간에 따른 변화와 주파수 구성이라는 서로 다른 관점으로 표현

* 주기와 주파수

  * 주기 $T$: 신호가 한 번 반복되는 데 걸리는 시간으로, 단위는 초(s)

  * 주파수 $f$: 1초 동안 반복되는 횟수로, 단위는 헤르츠(Hz)
    * 주기 신호의 기본 주파수는 $f_0 = 1/T$

  * 각주파수 $\omega$: 1초 동안 변화하는 위상각으로, 단위는 rad/s
    * $\omega = 2\pi f$, 기본 각주파수는 $\omega_0 = 2\pi/T$

* 진폭과 위상

  * 정현파 표현: $x(t) = A\cos(2\pi ft + \phi)$
    * $A$: 진폭으로, 정현파의 크기

    * $f$: 주파수로, 정현파의 반복 속도

    * $\phi$: 위상으로, 정현파의 주기 내 위치를 나타내는 각도

  * 주파수 스펙트럼
    * 주파수별 성분의 크기와 위상을 나타낸 것

    * 일반적으로 신호를 복원하려면 크기뿐 아니라 위상 정보도 필요

### 푸리에 급수의 개념과 수식

* 개념

  * 푸리에 급수(Fourier Series)
    * 주기 신호를 기본 주파수와 그 정수배 주파수를 갖는 정현파들의 합으로 표현

    * 주파수 성분이 $0, f_0, 2f_0, 3f_0, \ldots$처럼 이산적으로 존재

  * 표현 조건과 수렴
    * 구간별로 매끄러운 주기 신호 등 일반적인 공학 신호에 적용

    * 연속인 지점에서는 해당 신호 값으로, 점프 불연속 지점에서는 좌극한과 우극한의 평균으로 수렴

* 기본 수식

  * 삼각함수 형태

    $$x(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n\cos(n\omega_0t) + b_n\sin(n\omega_0t)\right]$$

  * 푸리에 계수
    * 한 주기 $[t_0, t_0+T]$에서 각 정현파 성분이 포함된 정도를 계산

    $$a_n = \frac{2}{T}\int_{t_0}^{t_0+T}x(t)\cos(n\omega_0t)\,dt \quad (n \geq 0)$$

    $$b_n = \frac{2}{T}\int_{t_0}^{t_0+T}x(t)\sin(n\omega_0t)\,dt \quad (n \geq 1)$$

  * 직류 성분(Direct Current, DC)
    * $a_0/2$는 한 주기 동안 신호의 평균값

    * 시간에 따라 변하지 않는 0 Hz 성분

### 고조파와 사각파 예시

* 고조파와 사각파

  * 고조파(Harmonic)
    * 기본 주파수의 정수배에 해당하는 성분

    * $nf_0$는 제$n$고조파이며, $f_0$는 기본파

  * 평균이 0이고 진폭이 $\pm1$인 대칭 사각파
    * 한 주기에서 $0<t<T/2$이면 $+1$, $T/2<t<T$이면 $-1$인 파형을 주기적으로 반복

    * 다음과 같이 홀수차 사인파 성분의 합으로 표현

    $$x(t) = \frac{4}{\pi}\left[\sin(\omega_0t) + \frac{1}{3}\sin(3\omega_0t) + \frac{1}{5}\sin(5\omega_0t) + \cdots\right]$$

  * 깁스 현상(Gibbs Phenomenon)
    * 불연속 신호를 유한 개의 푸리에 급수 항으로 근사하면 불연속점 부근에 진동과 초과 상승이 발생

    * 항 수가 증가하면 진동 구간은 좁아지지만 최대 초과 상승 비율은 0으로 사라지지 않음

### 푸리에 변환

* 변환과 역변환

  * 푸리에 변환(Fourier Transform, FT)
    * 시간 신호 $x(t)$를 주파수별 복소 성분 $X(f)$로 표현

    * 비주기 신호의 주파수 분석에 사용하며, 일반적으로 연속적인 주파수 스펙트럼을 다룸

    * 아래 식은 주파수 $f$를 Hz 단위로 사용하는 정의

    $$X(f) = \int_{-\infty}^{\infty}x(t)e^{-j2\pi ft}\,dt$$

  * 역푸리에 변환(Inverse Fourier Transform)
    * 주파수 성분을 합성하여 시간 신호를 복원

    $$x(t) = \int_{-\infty}^{\infty}X(f)e^{j2\pi ft}\,df$$

  * 복소수 표현
    * $j$는 $j^2=-1$을 만족하는 허수 단위

    * 오일러 공식 $e^{j\theta}=\cos\theta+j\sin\theta$로 사인·코사인 성분을 함께 표현

    * $|X(f)|$는 크기 스펙트럼, $\arg X(f)$는 위상 스펙트럼

* 푸리에 급수와의 관계

  * 주기 신호의 분해
    * 푸리에 급수는 일정 간격 $f_0=1/T$의 주파수 성분을 합산

  * 비주기 신호로의 확장
    * 유한 구간의 신호를 주기적으로 반복한 뒤 반복 주기 $T$를 늘리는 관점으로 이해

    * $T\to\infty$이면 주파수 간격 $1/T\to0$이 되어, 적절한 조건에서 이산적인 합이 연속적인 적분으로 연결

  * 주기 신호의 푸리에 변환
    * 푸리에 변환이 비주기 신호에만 적용되는 것은 아님

    * 주기 신호는 일반화된 함수인 디랙 델타를 사용하여 이산적인 선 스펙트럼으로 표현 가능

* 활용

  * 음성·음악 분석
    * 포함된 주파수 성분을 분석하여 음높이와 음색 등을 파악

  * 필터링
    * 주파수 영역에서 원하는 대역을 통과시키거나 줄인 뒤 역변환으로 신호 복원

    * 예: 고주파 잡음 감소, 특정 주파수의 간섭 제거

  * 영상 처리와 통신
    * 영상의 공간 주파수를 분석하여 평활화·윤곽 강조 등에 활용

    * 통신 신호의 대역폭과 주파수 구성 분석에 활용

### 이산 푸리에 변환과 고속 푸리에 변환

* 이산 푸리에 변환

  * 이산 푸리에 변환(Discrete Fourier Transform, DFT)
    * 유한한 $N$개의 이산 시간 표본을 $N$개의 주파수 성분으로 변환

    $$X[k] = \sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}, \quad k=0,1,\ldots,N-1$$

  * 주파수 간격
    * 샘플링 주파수가 $f_s$이면 주파수 빈(bin)의 간격은 $\Delta f=f_s/N$

    * $k$번째 빈은 $kf_s/N$에 대응하며, 배열 뒤쪽 빈은 음의 주파수로 해석할 수 있음

  * 해석 시 주의점
    * DFT는 입력된 $N$개 표본이 주기적으로 반복된다고 해석

    * 분석 구간에 정수 개 주기가 들어오지 않는 정현파는 여러 빈으로 성분이 퍼지는 스펙트럼 누설이 발생할 수 있음

    * 윈도 함수를 적용하면 누설을 줄일 수 있지만 주파수 분리 능력 등과 절충이 필요

* 고속 푸리에 변환

  * 고속 푸리에 변환(Fast Fourier Transform, FFT)
    * DFT를 효율적으로 계산하는 알고리즘의 총칭

    * 직접 계산한 DFT와 같은 변환 결과를 더 적은 연산으로 구함

  * 계산량
    * DFT 직접 계산: $O(N^2)$

    * 대표적인 FFT 알고리즘: $O(N\log N)$

* 핵심 비교

  * 푸리에 급수: 주기 신호 → 이산적인 주파수 성분들의 합

  * 푸리에 변환: 비주기 신호까지 다루는 주파수 표현 → 일반적으로 연속적인 주파수 성분의 적분

  * DFT: 유한한 이산 시간 표본 → 유한한 이산 주파수 성분

  * FFT: DFT를 빠르게 계산하는 알고리즘

### 나이퀴스트 정리

* 나이퀴스트 무잡음 채널 전송 용량
  * 잡음이 없는 이상적인 저역통과 채널에서 대역폭과 신호 레벨 수에 따른 최대 비트 전송률

  $$R_{\max}=2B\log_2 M$$

  * $B$: 채널 대역폭으로, 단위는 Hz

  * $M$: 서로 구별 가능한 신호 레벨 수

  * $R_{\max}$: 최대 비트 전송률로, 단위는 bit/s 또는 bps

* 수식의 의미
  * 이상적인 무심벌간 간섭 조건에서 최대 심벌 전송률은 $2B$ baud

  * 신호 레벨 수가 $M=2^k$이면 심벌 하나로 $k=\log_2 M$비트 표현

  * 비트 전송률 = 심벌 전송률 × 심벌당 비트 수

* 계산 예시
  * $B=3{,}000$ Hz, $M=4$이면 $R_{\max}=2\times3{,}000\times\log_2 4=12{,}000$ bps

* 나이퀴스트 표본화 정리와의 구분
  * 표본화 정리는 대역이 제한된 아날로그 신호를 표본으로부터 복원하기 위한 조건

  * 최고 주파수가 $f_{\max}$인 저역통과 신호는 일반적으로 $f_s>2f_{\max}$로 표본화해야 이상적으로 복원 가능

  * $2f_{\max}$는 나이퀴스트율이며, 정확히 같은 주파수로 표본화하면 경계 주파수 성분의 위상에 따라 복원이 불가능할 수 있음

  * 표본화 주파수의 절반인 $f_s/2$는 나이퀴스트 주파수

  * 표본화 조건을 만족하지 못하면 서로 다른 주파수 성분이 구별되지 않는 에일리어싱(Aliasing) 발생

### 섀넌 정리

* 섀넌 채널 용량 정리
  * 대역폭이 제한되고 가산성 백색 가우스 잡음이 존재하는 채널의 이론적 최대 정보 전송률

  $$C=B\log_2\left(1+\frac{S}{N}\right)$$

  * $C$: 채널 용량으로, 단위는 bps

  * $B$: 채널 대역폭으로, 단위는 Hz

  * $S$: 평균 수신 신호 전력

  * $N$: 해당 대역폭 내 평균 잡음 전력

  * $S/N$: 신호 대 잡음비(Signal-to-Noise Ratio, SNR)로, 수식에는 선형 전력비 사용

* 신호 대 잡음비의 단위 변환

  * 선형 전력비 → dB: `SNR(dB) = 10 × log₁₀(S/N)`
  * dB → 선형 전력비: `S/N = 10^(SNR(dB)/10)`
  * 30 dB이면 `S/N = 10^(30/10) = 1,000`이며, 섀넌 수식에 30을 그대로 대입하지 않음

* 계산 예시
  * $B=3{,}000$ Hz, $S/N=1{,}023$이면 $C=3{,}000\log_2(1{,}024)=30{,}000$ bps

* 채널 용량의 의미
  * 전송률이 용량보다 낮을 때 적절한 부호화와 충분히 긴 부호 길이를 사용하면 오류 확률을 임의로 작게 만들 수 있음

  * 실제 장비가 항상 용량과 같은 속도를 달성하거나 오류 없이 동작한다는 뜻은 아님

  * 신호 레벨 수만 늘려서는 잡음에 의한 용량 한계를 넘을 수 없음

### 나이퀴스트 정리와 섀넌 정리 비교

* 나이퀴스트 전송 용량 공식
  * 무잡음 채널을 가정하며 대역폭과 신호 레벨 수에 따른 전송률 한계 계산

  * 암기: $2B\log_2 M$

* 섀넌 채널 용량 공식
  * 잡음이 있는 채널에서 대역폭과 신호 대 잡음비에 따른 정보 전송률 한계 계산

  * 암기: $B\log_2(1+S/N)$

* 문제 풀이 기준
  * 신호 레벨 수가 주어지면 나이퀴스트 공식 검토

  * 신호 전력·잡음 전력 또는 신호 대 잡음비가 주어지면 섀넌 공식 검토

  * 두 제약이 모두 적용되면 각각의 한계를 계산하고 더 작은 값을 상한으로 사용

  * 이 상한이 특정 변조 방식과 장비에서 실제로 달성 가능함을 보장하지는 않음

## 전자기파 전파 모드 (3)

### TE 모드

* 횡전기 모드(Transverse Electric, TE)
  * 전기장이 전파 방향에 수직인 전자기파의 전파 모드

  * 정식 명칭은 Transverse Electronic이 아니라 Transverse Electric

* 전기장과 자기장 성분
  * 전파 방향을 $z$축으로 두면 전기장의 종방향 성분은 $E_z=0$

  * 자기장의 종방향 성분은 $H_z\neq0$이며, 자기장은 횡방향 성분도 가질 수 있음

  * 전기장 전체가 0이라는 뜻이 아니라 전파 방향의 전기장 성분이 없다는 뜻

### TM·TEM 모드와 비교

* 횡자기 모드(Transverse Magnetic, TM)
  * 자기장이 전파 방향에 수직인 모드

  * $H_z=0$, $E_z\neq0$

* 횡전자기 모드(Transverse Electromagnetic, TEM)
  * 전기장과 자기장이 모두 전파 방향에 수직인 모드

  * $E_z=0$, $H_z=0$

  * 이상적인 동축선이나 평행 2선식 전송선에서 전파 가능

* 암기 기준
  * TE: 전기장(E)의 종방향 성분이 0

  * TM: 자기장(H)의 종방향 성분이 0

  * TEM: 전기장과 자기장의 종방향 성분이 모두 0

### 도파관에서의 TE 모드

* 도파관(Waveguide)
  * 경계 구조를 이용하여 전자기파를 특정 방향으로 유도하는 전송 구조

  * 속이 빈 단일 도체 금속 도파관은 TE·TM 모드를 지원하며 TEM 모드는 지원하지 않음

* 차단 주파수(Cutoff Frequency)
  * 각 모드가 진행파로 전파되기 위한 주파수의 경계

  * 이상적인 균일 도파관에서 동작 주파수가 해당 모드의 차단 주파수보다 높아야 전파 가능

  * 차단 주파수 아래에서는 해당 모드의 장이 진행 방향으로 지수적으로 감쇠

* 직사각형 금속 도파관의 기본 모드
  * 내부 폭 $a$가 높이 $b$보다 클 때 가장 낮은 차단 주파수를 갖는 지배 모드는 $\mathrm{TE}_{10}$

  * 공기로 채워진 경우 차단 주파수는 근사적으로 $f_c=c/(2a)$이며, $c$는 진공 중 빛의 속도

> 참고: [Feynman Lectures — Waveguides](https://www.feynmanlectures.caltech.edu/II_24.html), [University of Virginia — Waveguides II](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_55_Waveguides_II.html)

## 동기식·비동기식 전송 (3)

### 동기식 전송방식

* 동기식 전송(Synchronous Transmission)
  * 송수신 측이 비트의 타이밍을 맞춘 상태에서 데이터를 블록이나 프레임 단위로 전송하는 방식

  * 문자마다 시작·정지 비트를 붙이지 않고 프레임 단위로 경계를 구분

* 동기 유지와 프레임 구분
  * 비트 타이밍은 별도의 클록 신호를 전달하거나 수신 신호에서 클록을 복원하여 맞춤

  * 프리앰블·동기 문자·플래그 등은 방식에 따라 동기 확보나 프레임 경계 구분에 사용

  * 비트 타이밍 동기와 프레임 경계 식별은 구분해서 이해

* 특징
  * 문자별 시작·정지 비트가 없어 대량 데이터를 연속 전송할 때 오버헤드 비율을 줄이기 유리

  * 프레임 헤더·트레일러·동기 정보 등의 오버헤드는 여전히 존재

  * 동기 유지와 프레임 처리를 위한 제어가 필요하며, 실제 속도와 효율은 사용하는 프로토콜과 장비에 따라 달라짐

### 비동기식 전송방식

* 비동기식 전송(Asynchronous Transmission)
  * 전통적인 시작·정지 방식에서는 문자마다 시작 비트로 수신 타이밍을 맞추고 정지 비트로 문자 종료를 구분

  * 문자 사이 간격은 일정하지 않아도 되지만, 한 문자 내부의 비트 간격은 설정된 전송 속도에 따라 일정

  * 송수신 측은 전송 속도, 데이터 비트 수, 패리티 사용 여부, 정지 비트 길이를 미리 맞춰야 함

* 문자 프레임 구성
  * 시작 비트 → 데이터 비트 → 선택적 패리티 비트 → 정지 비트

  * 일반적인 UART(Universal Asynchronous Receiver/Transmitter) 논리 신호에서 유휴 상태는 1, 시작 비트는 0, 정지 비트는 1

  * 실제 회선 전압의 극성은 사용하는 전기적 인터페이스에 따라 다를 수 있음

* 8N1 설정
  * 데이터 8비트, 패리티 없음(None), 정지 1비트로 구성하며 시작 1비트가 추가됨

  * 한 문자 전송에 총 10비트가 필요하므로, 문자 사이 유휴 시간이 없을 때 데이터 비트 효율은 $8/10=80\%$

  * 9,600 bit/s로 연속 전송하면 초당 최대 $9{,}600/10=960$문자이며 순수 데이터율은 $960\times8=7{,}680$ bit/s

  * 위 계산은 상위 프로토콜의 추가 오버헤드를 제외한 값이며, 문자 사이 유휴 시간이 있으면 실제 처리율은 감소

* 특징
  * 필요할 때 문자 단위로 전송하기 쉬워 간헐적인 소량 데이터 전송에 적합

  * 문자마다 시작·정지 비트가 붙어 부가 비트의 비율이 커질 수 있음

### 동기식·비동기식 비교

* 동기 기준
  * 동기식: 프레임 전송 중 비트 타이밍 동기 유지

  * 비동기식: 각 문자의 시작 비트에서 타이밍을 다시 맞추며, 문자 사이 간격은 가변적

* 전송 단위와 부가 정보
  * 동기식: 블록·프레임 단위로 전송하며 프레임별 제어 정보 사용

  * 비동기식: 문자 단위로 시작·정지 비트를 사용하고 필요하면 패리티 추가

* 구분 시 주의점
  * 비동기식도 문자 내부의 비트 동기가 필요하므로 동기가 전혀 없는 방식은 아님

  * 동기식도 반드시 별도의 클록 선을 사용하는 것은 아님

  * 이 구분은 시간 동기와 프레이밍에 관한 것으로, 직렬·병렬이나 단방향·반이중·전이중 구분과는 별개

  * 동기식 TDM의 고정 슬롯 배정과 비동기식 전송의 시작·정지 방식은 서로 다른 분류 기준

* 암기 핵심
  * 동기식: 프레임 단위 → 동기 유지 → 대량 연속 전송에 유리

  * 비동기식: 문자 단위 → 시작·정지 비트 → 문자 사이 간격 가변

## 펄스 부호 변조 (5)

### PCM 개념과 처리 순서

* 펄스 부호 변조(Pulse Code Modulation, PCM)
  * 아날로그 신호를 일정한 시간 간격으로 측정하고, 측정값을 유한한 레벨로 근사한 뒤 디지털 비트열로 표현하는 방식

* 송신 과정
  * 표본화(Sampling) → 양자화(Quantization) → 부호화(Encoding)

  * 표본화는 시간을 이산화하고, 양자화는 진폭을 이산화하며, 부호화는 양자화된 값을 비트열로 표현

* 수신 과정
  * 비트열 복호화 → 양자화 레벨에 대응하는 표본값 생성 → 복원 필터로 아날로그 신호 복원

  * 양자화 과정에서 잃은 정보는 일반적으로 완전히 복원할 수 없음

### 표본화

* 표본화 주파수와 주기
  * 표본화 주파수 $f_s$: 1초 동안 취하는 표본 수로, 단위는 Hz 또는 samples/s

  * 표본화 주기 $T_s$: 인접한 표본 사이의 시간 간격으로, $T_s=1/f_s$

* 표본화 조건
  * 최고 주파수가 $f_{\max}$인 대역 제한 저역통과 신호는 일반적으로 $f_s>2f_{\max}$로 표본화

  * 시험에서는 최소 표본화 주파수를 $2f_{\max}$로 계산하는 경우가 많으며, 실제 설계에서는 필터의 특성을 고려하여 여유를 둠

* 에일리어싱 방지
  * 표본화 전에 저역통과 필터를 적용하여 $f_s/2$ 이상의 주파수 성분을 충분히 억제

  * 표본화 이후에는 겹쳐진 주파수 성분을 일반적으로 원래대로 분리할 수 없음

### 양자화

* 양자화 레벨과 비트 수
  * 연속적인 표본 진폭을 유한한 대표값 중 하나로 근사

  * 표본당 비트 수가 $n$이면 표현 가능한 양자화 레벨 수는 $L=2^n$

  * 예: 8비트 양자화는 256개 레벨 표현

* 균일 양자화
  * 양자화 간격을 일정하게 설정하는 방식

  * 입력 범위가 $V_{\min}$부터 $V_{\max}$까지이고 이를 $L$개의 동일한 구간으로 나누면 양자화 간격은 $\Delta=(V_{\max}-V_{\min})/L$

* 양자화 오차와 잡음
  * 실제 표본값과 양자화된 대표값의 차이가 양자화 오차

  * 각 구간의 중앙값으로 반올림하고 입력이 양자화 범위를 벗어나지 않으면 오차 크기는 최대 $\Delta/2$

  * 비트 수를 늘리면 양자화 간격과 양자화 잡음이 감소하지만 필요한 전송률은 증가

  * 입력이 허용 범위를 벗어나면 과부하 왜곡이 발생

* 비균일 양자화와 압신
  * 작은 진폭에는 좁은 간격을, 큰 진폭에는 넓은 간격을 적용하여 작은 신호의 상대적인 양자화 오차를 줄임

  * 압신(Companding): 송신 측에서 진폭을 압축하고 수신 측에서 신장하는 방식

  * 대표적인 압신 특성은 A-law와 μ-law

### 부호화와 전송률

* 부호화
  * 각 양자화 레벨에 대응하는 이진 부호를 부여

  * PCM의 부호화는 표본값을 비트열로 표현하는 단계이며, 오류 정정 부호화나 전송용 선로 부호화와 구분

* PCM 비트 전송률

  $$R_b=f_s\times n$$

  * $R_b$: 비트 전송률로, 단위는 bps

  * $f_s$: 초당 표본 수

  * $n$: 표본당 비트 수

  * 동일한 조건의 $K$개 채널을 다중화하면 순수 PCM 데이터 전송률은 $Kf_sn$

  * 동기·제어·오류 정정 비트가 추가되면 실제 필요한 전송률은 더 커짐

* 음성 PCM 계산 예시
  * 표본화 주파수 8,000 Hz, 표본당 8비트이면 $R_b=8{,}000\times8=64{,}000$ bps = 64 kbps

  * 표본화 주기는 $T_s=1/8{,}000=125$ μs

  * 여기서 64 kbps는 비트 전송률이며, 전송에 필요한 채널 대역폭은 선로 부호와 변조 방식 등에 따라 달라짐

### PCM 특징과 관련 방식

* 장점과 한계
  * 디지털 신호의 재생과 오류 제어가 가능하며 저장·처리·다중화에 적합

  * 표본화와 양자화에 따른 제약이 있으며, 높은 품질을 위해 표본화 주파수나 비트 수를 늘리면 전송 데이터량 증가

* 차분·적응 부호화
  * DPCM과 ADPCM의 원리 및 ADM과의 차이는 [예측 부호화와 적응 변조](#예측-부호화와-적응-변조-2) 참고

* 델타 변조(Delta Modulation, DM)
  * 이전 복원값을 기준으로 증가·감소 방향을 표본당 1비트로 표현하는 방식

  * 신호 변화가 계단의 추종 속도보다 빠르면 경사 과부하 왜곡, 완만한 구간에서는 계단 변화에 따른 입상 잡음 발생

* 암기 핵심
  * 처리 순서: 표본화 → 양자화 → 부호화

  * 레벨 수: $L=2^n$

  * 전송률: $R_b=f_sn$

  * 대표 음성 PCM: 8 kHz × 8비트 = 64 kbps

## 예측 부호화와 적응 변조 (2)

### DPCM

* 차분 펄스 부호 변조(Differential Pulse Code Modulation, DPCM)
  * 현재 표본값 자체 대신 현재 표본값과 예측값의 차이를 양자화하여 부호화하는 방식

  * 인접 표본 사이의 상관관계를 이용하며, 예측 오차의 범위가 작으면 같은 품질에 필요한 비트 수를 줄일 수 있음

* 처리 과정
  * 과거 복원 표본으로 현재 값 예측 → 현재 표본과 예측값의 차이 계산 → 차분 양자화 → 부호화

  * 수신 측은 송신 측과 같은 예측 규칙을 사용하고, 예측값에 복호화한 차분을 더하여 표본을 복원

  * 송신 측도 양자화된 차분으로 복원한 표본을 예측에 사용하여 수신 측과 예측 상태를 맞춤

* PCM과의 비교
  * 펄스 부호 변조(Pulse Code Modulation, PCM): 표본의 진폭값을 양자화하여 표현

  * DPCM: 표본의 예측 오차를 양자화하여 표현

  * 직전 표본만 이용하는 단순 예측에서는 차분을 구하지만, 일반적으로 여러 과거 표본으로 예측 가능

### ADM

* 적응 델타 변조(Adaptive Delta Modulation, ADM)
  * 델타 변조(Delta Modulation, DM)의 계단 크기를 입력 신호의 변화에 따라 조절하는 방식

  * 기본 DM처럼 표본마다 이전 복원값에 대한 증가·감소 방향을 1비트로 표현

* 계단 크기 조절
  * 같은 방향의 비트가 연속되면 계단 크기를 늘려 빠른 신호 변화를 추종

  * 증가·감소 방향이 자주 교대하면 계단 크기를 줄여 완만한 구간의 오차를 감소

  * 수신 측도 동일한 적응 규칙으로 계단 크기를 갱신하여 복원

* 개선하는 왜곡
  * 경사 과부하 왜곡: 계단의 추종 속도보다 입력 신호의 변화가 빨라 발생하며, 계단 크기를 늘려 완화

  * 입상 잡음: 완만한 신호 주위에서 계단이 오르내리며 발생하며, 계단 크기를 줄여 완화

  * 적응으로 두 문제를 줄일 수 있지만 모든 입력에서 완전히 제거되는 것은 아님

* ADPCM과의 구분
  * 적응 차분 펄스 부호 변조(Adaptive Differential Pulse Code Modulation, ADPCM): DPCM의 양자화 간격이나 예측 특성 등을 적응적으로 조절

  * ADM: 기본적으로 1비트 델타 변조의 계단 크기를 조절

> PCM의 표본화·양자화·부호화와 전송률 계산은 [펄스 부호 변조](#펄스-부호-변조-5) 단원 참고

## 다중화 (3)

### TDM

* 시분할 다중화(Time Division Multiplexing, TDM)
  * 하나의 전송 회선을 시간 슬롯으로 나누어 여러 채널이 번갈아 사용하는 방식

  * 수신 측은 시간 슬롯을 구분하여 각 채널의 데이터를 분리하므로 송수신 간 동기 필요

* 동기식 TDM
  * 각 채널에 정해진 시간 슬롯을 주기적으로 할당

  * 보낼 데이터가 없는 채널에도 슬롯이 배정되어 회선 이용 효율이 낮아질 수 있음

* 통계적 TDM
  * 전송할 데이터가 있는 채널에 시간 슬롯을 동적으로 할당

  * 채널 식별 정보와 버퍼가 필요하며, 트래픽이 집중되면 대기 지연 발생

* 전송률 계산
  * 각 채널의 입력률이 $r$ bps이고 $K$개 채널을 고정 슬롯으로 수용하면 순수 데이터 전송률은 $Kr$ bps

  * 동기·제어 비트가 있으면 실제 회선 전송률에 추가 반영

  * 예: 64 kbps PCM 채널 24개를 수용하면 순수 데이터 전송률은 $24\times64=1{,}536$ kbps

### FDM

* 주파수 분할 다중화(Frequency Division Multiplexing, FDM)
  * 전송 매체의 주파수 대역을 여러 부대역으로 나누어 각 채널을 동시에 전송하는 방식

  * 각 신호를 서로 다른 반송파 주파수에 실어 대역이 겹치지 않게 배치

* 보호 대역(Guard Band)
  * 인접 채널 간 간섭을 줄이기 위해 채널 사이에 두는 주파수 간격

  * 보호 대역과 필터의 특성 때문에 실제 필요한 대역폭은 신호 대역폭의 단순 합보다 커질 수 있음

* 대역폭 계산
  * 각 변조 채널의 점유 대역폭이 $B$, 채널 수가 $K$, 인접 채널 사이 보호 대역폭이 $G$이면 전체 대역폭은 $KB+(K-1)G$

  * 위 식은 양 끝의 추가 여유 대역을 제외하고, 인접 채널 사이에만 동일한 보호 대역을 두는 경우

  * 예: 4 kHz 채널 3개, 보호 대역 1 kHz이면 $3\times4+2\times1=14$ kHz

* 활용
  * 방송 신호 분배, 케이블 전송 등에서 여러 주파수 채널을 하나의 매체로 전달

### TDM과 FDM 비교

* 자원 분할 기준
  * TDM: 시간으로 구분하며 각 채널이 순서대로 전송

  * FDM: 주파수로 구분하며 각 채널이 서로 다른 대역에서 동시에 전송

* 채널 분리에 필요한 요소
  * TDM: 시간 슬롯과 프레임 동기

  * FDM: 주파수 선택 필터와 보호 대역

* 신호 종류와의 관계
  * TDM은 디지털 통신, FDM은 아날로그 통신에서 대표적으로 사용

  * FDM으로 디지털 변조 신호도 전송할 수 있으므로 신호 종류만으로 두 방식을 단정하지 않음

* 암기 핵심
  * TDM: 시간 슬롯 분할

  * FDM: 주파수 대역 분할

## 회선 제어와 다중 접근 (4)

### ALOHA

* 임의 접근 방식
  * 여러 단말이 공유 매체에 경쟁적으로 접근하며, 전송 전에 채널이 사용 중인지 감지하지 않음

  * 프레임이 겹쳐 충돌하면 전송에 실패할 수 있으며, 확인 응답이 오지 않으면 임의의 시간을 기다린 뒤 재전송

* 순수 ALOHA(Pure ALOHA)
  * 전송할 프레임이 생기면 시각 제한 없이 바로 전송

  * 프레임 전송 시간이 모두 $T$일 때 충돌 취약 구간은 $2T$

* 슬롯 ALOHA(Slotted ALOHA)
  * 시간을 프레임 하나의 전송 시간과 같은 슬롯으로 나누고 슬롯 시작에만 전송

  * 단말 사이의 슬롯 동기가 필요하며 충돌 취약 구간은 $T$

  * 같은 슬롯에서 여러 단말이 전송하면 충돌할 수 있으므로 충돌을 완전히 제거하는 방식은 아님

* 이론적 최대 처리율
  * 같은 길이의 프레임, 포아송 전송 시도, 프레임이 겹치면 실패하는 이상적인 모형을 가정

  * $G$: 프레임 전송 시간당 평균 전송 시도 수로, 재전송도 포함

  * $S$: 프레임 전송 시간당 평균 성공 프레임 수

  * 순수 ALOHA: $S=Ge^{-2G}$이며 $G=1/2$에서 최대 $1/(2e)\approx0.184$, 약 18.4%

  * 슬롯 ALOHA: $S=Ge^{-G}$이며 $G=1$에서 최대 $1/e\approx0.368$, 약 36.8%

### Polling

* 폴링(Polling)
  * 주국(Primary Station)이 종국(Secondary Station)에 보낼 데이터가 있는지 묻고 송신 기회를 부여하는 방식

  * 제어 요청은 주국 → 종국, 실제 데이터는 종국 → 주국 방향

* 기본 동작
  * 주국의 POLL 전송 → 종국의 데이터 전송 → 주국의 수신 확인

  * 보낼 데이터가 없으면 종국은 해당 프로토콜의 규칙에 따라 부정 응답 등을 보내고 주국은 다음 종국 확인

* 특징
  * 주국이 전송 기회를 통제하므로 통제된 단말 사이의 경쟁 충돌을 방지할 수 있음

  * 데이터가 없는 종국을 확인하는 제어 오버헤드와 자신의 차례를 기다리는 지연 발생

  * 중앙 주국에 의존하는 구성에서는 주국 장애가 통신 전체에 영향을 줄 수 있음

### Selecting

* 셀렉팅(Selecting)
  * 주국이 데이터를 보낼 종국을 선택하고 수신 준비 상태를 확인하는 방식

  * 제어 요청과 실제 데이터 모두 주국 → 종국 방향

* 기본 동작
  * 주국의 SEL 전송 → 종국의 수신 가능 응답 → 주국의 데이터 전송 → 종국의 수신 확인

  * 종국이 수신할 수 없으면 부정 응답 등에 따라 전송을 보류하거나 재시도

  * 위 순서는 기본 방식이며, 선택 요청과 데이터를 연달아 보내는 변형도 있음

### ALOHA·Polling·Selecting 비교

* 접근 제어 주체
  * ALOHA: 단말이 자율적으로 전송을 시도하는 경쟁 방식

  * Polling·Selecting: 주국이 종국의 송수신을 통제하는 방식

* 주국의 목적
  * Polling: 종국이 보낼 데이터를 받아오기

  * Selecting: 선택한 종국으로 데이터를 보내기

* 암기 핵심
  * ALOHA: 일단 전송 → 실패 시 임의 대기 → 재전송

  * Polling: 주국이 묻고 종국이 송신

  * Selecting: 주국이 선택하고 주국이 송신
