## 결합도(Coupling) 단계를 약한 순서에서 강한 순서로 가장 올바르게 표시한 것은? (1.3.5 - 모듈)

① Control → Data → Stamp → Common → Content

② Control → Data → Stamp → Common → Content

③ Content → Stamp → Control → Common → Data

## 해싱 함수(Hashing Function)의 종류가 아닌 것은? (2.1.4 이분 탐색, 해싱)

## 다음 데이터베이스 무결성 제약 중 '개체 무결성 제약' 조건에 대한 설명으로 맞는 것은? (3.1.6: 관계형 데이터베이스의 제약조건 - 무결성)

① 데이터 내의 특성들이 각 속성이 정의된 소속 도메인에 지정된 값을 가져야 한다.

② 릴레이션의 기본키를 구성하는 어떤 속성값도 널 값이나 중복값을 가질 수 없다.

③ 릴레이션은 참조할 수 없는 외래키 값을 가질 수 없다.

④ 릴레이션의 기본키를 구성하는 속성값은 중복값을 가질 수 있지만 널 값을 가질 수 없다.

> **정답: ②**
> 개체 무결성: 기본키는 NULL과 중복값 모두 불가. ①=도메인 무결성, ③=참조 무결성, ④=일부만 맞음(중복도 불가).
