## 생성 패턴

### Abstract Factory

* 관련 객체군을 구체 클래스에 의존하지 않고 생성할 때 사용

```java
interface Widget {
    void paint();
}

class DeskWidget implements Widget {
    public void paint() {
        System.out.println("desk widget");
    }
}

class MobileWidget implements Widget {
    public void paint() {
        System.out.println("mobile widget");
    }
}

interface ScreenKit {
    Widget widget();
}

class DeskKit implements ScreenKit {
    public Widget widget() {
        return new DeskWidget();
    }
}

class MobileKit implements ScreenKit {
    public Widget widget() {
        return new MobileWidget();
    }
}
```

### Builder

* 복잡한 객체를 단계별로 생성할 때 사용

```java
class User {
    private String name;
    private int age;

    private User(Draft draft) {
        this.name = draft.name;
        this.age = draft.age;
    }

    static class Draft {
        private String name;
        private int age;

        Draft name(String name) {
            this.name = name;
            return this;
        }

        Draft age(int age) {
            this.age = age;
            return this;
        }

        User done() {
            return new User(this);
        }
    }
}
```

### Factory Method

* 객체 생성을 서브클래스에 위임할 때 사용

```java
interface Document {
    void open();
}

class PdfDocument implements Document {
    public void open() {
        System.out.println("PDF open");
    }
}

abstract class DocumentJob {
    abstract Document prepare();
}

class PdfJob extends DocumentJob {
    Document prepare() {
        return new PdfDocument();
    }
}
```

### Prototype

* 기존 객체를 복제하여 새 객체를 만들 때 사용

```java
class Report {
    String title;

    Report(String title) {
        this.title = title;
    }

    Report twin() {
        return new Report(title);
    }
}
```

### Singleton

* 인스턴스를 하나만 만들고 전역 접근점을 제공할 때 사용

```java
class Settings {
    private static final Settings MAIN = new Settings();

    private Settings() {
    }

    static Settings current() {
        return MAIN;
    }
}
```

## 구조 패턴

### Adapter

* 호환되지 않는 인터페이스를 변환할 때 사용

```java
interface UsbC {
    void connectUsbC();
}

class UsbA {
    void connectUsbA() {
        System.out.println("USB-A connected");
    }
}

class CableJack implements UsbC {
    private UsbA usbA;

    CableJack(UsbA usbA) {
        this.usbA = usbA;
    }

    public void connectUsbC() {
        usbA.connectUsbA();
    }
}
```

### Bridge

* 추상화와 구현을 분리하여 각각 확장할 때 사용

```java
interface Color {
    String fill();
}

class Red implements Color {
    public String fill() {
        return "red";
    }
}

abstract class Shape {
    protected Color color;

    Shape(Color color) {
        this.color = color;
    }

    abstract void draw();
}

class Circle extends Shape {
    Circle(Color color) {
        super(color);
    }

    void draw() {
        System.out.println("circle " + color.fill());
    }
}
```

### Composite

* 단일 객체와 복합 객체를 같은 방식으로 처리할 때 사용

```java
import java.util.ArrayList;
import java.util.List;

interface Node {
    int size();
}

class FileNode implements Node {
    public int size() {
        return 1;
    }
}

class FolderNode implements Node {
    private List<Node> children = new ArrayList<>();

    void add(Node node) {
        children.add(node);
    }

    public int size() {
        return children.stream().mapToInt(Node::size).sum();
    }
}
```

### Decorator

* 기존 객체에 기능을 동적으로 추가할 때 사용

```java
interface Coffee {
    int cost();
}

class PlainCoffee implements Coffee {
    public int cost() {
        return 3000;
    }
}

class MilkCoffee implements Coffee {
    private Coffee coffee;

    MilkCoffee(Coffee coffee) {
        this.coffee = coffee;
    }

    public int cost() {
        return coffee.cost() + 500;
    }
}
```

### Facade

* 복잡한 서브시스템을 단순한 인터페이스로 감쌀 때 사용

```java
class Cpu {
    void start() {
        System.out.println("CPU start");
    }
}

class Memory {
    void load() {
        System.out.println("memory load");
    }
}

class Computer {
    private Cpu cpu = new Cpu();
    private Memory memory = new Memory();

    void boot() {
        cpu.start();
        memory.load();
    }
}
```

### Flyweight

* 같은 객체를 공유하여 메모리 사용을 줄일 때 사용

```java
import java.util.HashMap;
import java.util.Map;

class Icon {
    private String type;

    Icon(String type) {
        this.type = type;
    }
}

class IconStore {
    private Map<String, Icon> cache = new HashMap<>();

    Icon getIcon(String type) {
        return cache.computeIfAbsent(type, Icon::new);
    }
}
```

### Proxy

* 실제 객체 접근을 대신 제어할 때 사용

```java
interface Image {
    void display();
}

class PhotoFile implements Image {
    public void display() {
        System.out.println("display image");
    }
}

class LazyImage implements Image {
    private PhotoFile image;

    public void display() {
        if (image == null) {
            image = new PhotoFile();
        }
        image.display();
    }
}
```

## 행위 패턴

### Chain of Responsibility

* 요청을 처리할 수 있는 객체까지 전달할 때 사용

```java
abstract class SupportDesk {
    protected SupportDesk next;

    SupportDesk link(SupportDesk next) {
        this.next = next;
        return next;
    }

    abstract void answer(int level);
}

class LevelOneDesk extends SupportDesk {
    void answer(int level) {
        if (level <= 1) {
            System.out.println("info handled");
        } else if (next != null) {
            next.answer(level);
        }
    }
}
```

### Command

* 요청을 객체로 캡슐화할 때 사용

```java
interface Task {
    void run();
}

class Light {
    void on() {
        System.out.println("light on");
    }
}

class LightOnTask implements Task {
    private Light light;

    LightOnTask(Light light) {
        this.light = light;
    }

    public void run() {
        light.on();
    }
}
```

### Interpreter

* 간단한 언어 규칙을 객체로 표현하고 해석할 때 사용

```java
interface Rule {
    boolean matches(String context);
}

class WordRule implements Rule {
    private String word;

    WordRule(String word) {
        this.word = word;
    }

    public boolean matches(String context) {
        return context.contains(word);
    }
}
```

### Iterator

* 컬렉션 내부 구조를 노출하지 않고 순회할 때 사용

```java
import java.util.List;

class BookShelf {
    private List<String> books;
    private int cursor;

    BookShelf(List<String> books) {
        this.books = books;
    }

    boolean hasBook() {
        return cursor < books.size();
    }

    String nextBook() {
        return books.get(cursor++);
    }
}
```

### Mediator

* 객체들이 직접 참조하지 않고 중재자를 통해 통신할 때 사용

```java
class ChatRoom {
    void send(String user, String message) {
        System.out.println(user + ": " + message);
    }
}

class ChatUser {
    private String name;
    private ChatRoom room;

    ChatUser(String name, ChatRoom room) {
        this.name = name;
        this.room = room;
    }

    void send(String message) {
        room.send(name, message);
    }
}
```

### Memento

* 객체 상태를 저장하고 나중에 복원할 때 사용

```java
class Snapshot {
    String text;

    Snapshot(String text) {
        this.text = text;
    }
}

class Editor {
    private String text;

    void write(String text) {
        this.text = text;
    }

    Snapshot point() {
        return new Snapshot(text);
    }

    void backTo(Snapshot snapshot) {
        text = snapshot.text;
    }
}
```

### Observer

* 객체 상태 변화가 생기면 의존 객체에 자동 통지할 때 사용

```java
import java.util.ArrayList;
import java.util.List;

interface Phone {
    void receive(String news);
}

class NewsAgency {
    private List<Phone> phones = new ArrayList<>();

    void add(Phone phone) {
        phones.add(phone);
    }

    void publish(String news) {
        for (Phone phone : phones) {
            phone.receive(news);
        }
    }
}
```

### State

* 상태에 따라 객체 행동을 바꿀 때 사용

```java
interface DoorMode {
    void move();
}

class OpenMode implements DoorMode {
    public void move() {
        System.out.println("open");
    }
}

class Door {
    private DoorMode mode;

    void setMode(DoorMode mode) {
        this.mode = mode;
    }

    void request() {
        mode.move();
    }
}
```

### Strategy

* 알고리즘을 캡슐화하고 실행 시점에 교체할 때 사용

```java
interface SortRule {
    void arrange();
}

class QuickRule implements SortRule {
    public void arrange() {
        System.out.println("quick sort");
    }
}

class Sorter {
    private SortRule rule;

    Sorter(SortRule rule) {
        this.rule = rule;
    }

    void sort() {
        rule.arrange();
    }
}
```

### Template Method

* 알고리즘 골격은 상위 클래스에 두고 세부 단계만 하위 클래스에서 구현할 때 사용

```java
abstract class DataProcessor {
    final void process() {
        read();
        parse();
        save();
    }

    abstract void read();

    abstract void parse();

    void save() {
        System.out.println("save");
    }
}
```

### Visitor

* 객체 구조는 유지하고 새로운 연산을 추가할 때 사용

```java
interface SaleItem {
    void priceBy(PricingRule rule);
}

interface PricingRule {
    void apply(Book book);
}

class Book implements SaleItem {
    public void priceBy(PricingRule rule) {
        rule.apply(this);
    }
}

class DiscountRule implements PricingRule {
    public void apply(Book book) {
        System.out.println("calculate price");
    }
}
```
